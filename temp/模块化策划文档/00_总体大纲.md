## 1. 游戏定位

《力学大乱斗》是一款 2D 俯视视角的多人物理卡牌竞技游戏。玩家操控不同科学学派风格的角色，在实验场景中使用基础卡、属性卡和特殊卡改变运动规则，通过撞击、击飞、控制场地、制造连锁反应来淘汰对手。

核心关键词：

- 物理乱斗
- 卡牌构筑
- 掷骰随机
- 科学属性流派
- 短局竞技
- 高可读性连招
- 场景机制互动

---

## 2. 一句话卖点

用卡牌打出物理公式，用骰子制造实验误差，把对手从实验台上“科学地”弹出去。

## 4. 核心体验目标

### 4.1 玩家体验

玩家在一局游戏中应该经历以下循环：

1. 判断自己和敌人的位置、速度、状态。
2. 从手牌中选择合适卡牌。
3. 掷骰结算卡牌强度或附加效果。
4. 通过物理效果改变场上局面。
5. 把敌人推向边缘、墙体、陷阱或场景机制。
6. 通过连招完成击飞或结构崩坏。

### 4.2 观众体验

观众即使不了解具体公式，也要能看懂：

- 谁被什么力推走了。
- 谁正在被引力吸住。
- 正负电荷为什么会吸引或排斥。
- 哪个玩家打出了高点数骰子。
- 谁通过连锁操作完成击杀。

### 4.3 设计支柱

| 支柱 | 说明 |
| --- | --- |
| 物理可读 | 所有力、速度、轨迹、状态都要视觉化 |
| 卡牌策略 | 玩家通过手牌选择和构筑体现风格 |
| 可控随机 | 骰子增加变化，但每张牌必须有保底效果 |
| 短局高光 | 单局节奏快，允许翻盘，适合重复游玩 |
| 科学浪漫 | 概念来自科学，但表达必须好懂、好玩 |

## 6. 世界观概述

近未来，跨学科研究机构“范式实验院”发明了法则投影环。它可以把抽象的公式、定理和物理法则临时投影为可交互的战斗效果。

为了争夺实验经费、论文署名和年度最强学派称号，研究员们制造出“实验代理体”，让不同科学流派在安全实验场内进行竞技决斗。

玩家操控的不是历史人物本人，而是各个科学概念拟人化后的战斗代理：

- 经典力学代表高质量、防反和冲撞。
- 电磁学代表正负电荷、连锁爆发和极性控制。
- 数学代表降维、投影、减半、空间变换。
- 热学代表过热、熵增、持续区域压制。
- 光学代表反射、折射、镜像、视觉误导。
- 引力代表吸引、轨道、坍缩和弹弓加速。
- 概率与量子代表更高随机性和娱乐扩展。

## 7. 核心系统总览

### 7.1 人物系统

每个角色由以下部分组成：

| 模块 | 说明 |
| --- | --- |
| 人物定位 | 例如重型防反、机动刺客、空间控制 |
| 属性点 | 质量、机动、控场、爆发、稳定、难度 |
| 被动技能 | 长期改变打法 |
| 主动技能 | 短冷却，制造战斗节奏 |
| 终极技能 | 高影响力技能，需要铺垫或预判 |
| 推荐卡组 | 适合该角色的基础卡和属性卡 |

详见：`01_人物设计大纲.md`

### 7.2 卡牌系统

卡牌分为三层：

| 层级 | 说明 |
| --- | --- |
| 基础卡 | 所有人可用，负责移动、防御、通用攻击、资源 |
| 属性卡 | 按科学属性分类，决定构筑风格 |
| 特殊卡 | 高风险、高随机、角色专属、场景限定或终极级卡牌 |

属性卡首发推荐：

- 力学
- 电学
- 数学

后续扩展：

- 引力
- 热学
- 光学
- 概率
- 量子

详见：`02_卡牌设计大纲.md`

### 7.3 骰子系统

骰子用于增加实验随机性。大多数掷骰牌采用“保底效果 + 骰子强化”的设计。

示例：

- 掷 1：保底效果，可能轻微失准。
- 掷 2-3：正常效果。
- 掷 4-5：强化效果。
- 掷 6：暴击实验，触发额外效果。

设计原则：

1. 防御牌不能因为低点数完全失效。
2. 高风险牌可以有负面骰面，但必须写清楚。
3. 角色和卡牌可以修正骰子。
4. 排位模式限制高随机特殊卡。

详见：`02_卡牌设计大纲.md`

### 7.4 玩法系统

对局由以下系统构成：

- 移动与冲量
- 能量与手牌
- 碰撞与结构伤害
- 出界与回场
- 状态与抗性
- 掷骰结算
- 连招与击杀归属
- 地图机制

详见：`03_玩法大纲.md`

### 7.5 场景系统

场景不只是背景，而是战斗规则的一部分。

场景会影响：

- 摩擦
- 边界
- 引力
- 电荷
- 轨道
- 热量
- 视野与预览线
- 地图目标

详见：`04_场景大纲.md`

## 8. 胜利方式总览

| 胜利方式 | 说明 | 适用模式 |
| --- | --- | --- |
| 地形杀 | 把敌人击出安全边界 | 1v1、混战、团队 |
| 结构崩坏 | 通过高速碰撞把稳定性打到 0 | 标准局、新手局 |
| 计分胜利 | 限时内通过击飞、占点、连锁得分 | 多人混战 |
| 团队目标 | 保护核心、争夺实验目标、合作击飞 | 2v2 |
| 突然死亡 | 超时后场地收缩，强制决胜 | 所有竞技模式 |

## 12. 项目验收标准

首个可玩版本应满足：

1. 玩家 30 秒内知道如何移动、出牌、赢得对局。
2. 玩家第一次被击飞时能看懂主要原因。
3. 每张卡牌都有明确视觉反馈。
4. 骰子结果能影响局势，但不会让低点数完全无事可做。
5. 至少能打出 3 种连招：冲刺撞击、电荷脉冲、摩擦/冰面地形杀。
6. 一局能自然在 3-6 分钟内结束。
7. 观众能从画面上理解“科学规则正在打架”。
