## 1. 一句话概念

《力学大乱斗》是一款把物理公式、数学悖论和卡牌策略转化为即时战斗手感的多人竞技游戏。玩家操控不同学派角色，在会变化的实验场中打出卡牌，改变速度、质量、摩擦、电荷、引力和旋转规则，把对手撞出场外或击碎结构稳定性。

---

## 2. 核心体验目标

### 2.1 玩家应该感受到什么

1. 每张卡牌都像一个可见的物理法则，而不是普通技能换皮。
2. 胜负来自“预测、诱导、反制、撞击”的组合，而不是单纯比反应。
3. 物理效果要夸张、直观、好笑，但底层逻辑要自洽。
4. 玩家能看懂失败原因：为什么被吸过去、为什么被弹飞、为什么刹不住。
5. 高手局应该出现“连锁实验”：先赋予电荷，再制造引力场，最后用角动量把自己弹射出去。

### 2.2 三个设计支柱

#### 支柱一：物理可读性

所有重要效果必须有明确视觉表达：

- 力的方向：用箭头、尾迹、压缩线表示。
- 速度大小：用拖尾长度和镜头轻微拉伸表示。
- 电荷状态：正电荷为红色加号环，负电荷为蓝色减号环。
- 引力场：用向心粒子流和空间网格弯曲表示。
- 摩擦变化：用地面纹理、刹车火花、速度拖尾变短表示。
- 旋转与角动量：用环形轨迹线、弧形箭头和角色自旋表示。

#### 支柱二：卡牌是规则工具

卡牌不只是造成伤害，而是临时修改场上的物理规则。玩家的乐趣来自“我用这个规则让你进入那个规则，再用第三个规则结算”。

#### 支柱三：短局、高翻盘、低挫败

被击飞可以很戏剧化，但单局短，复活快，失败原因清楚。游戏应鼓励玩家立刻再来一局，而不是被数值压制后失去参与感。

## 3. 世界观与美术基调

### 3.1 世界设定

近未来，一所名为“范式实验院”的跨学科研究机构发现了一种可以把抽象公式实体化的装置：法则投影环。研究员们为了争夺年度经费、论文署名和实验场使用权，开始用物理法则进行安全边界内的竞技决斗。

玩家扮演不同学派的“实验代理体”。他们不是真实历史人物，而是从经典理论中抽象出来的角色人格，例如经典力学、统计物理、电磁学、拓扑几何、计算理论等。

### 3.2 美术方向

主风格：清晰、干净、科技实验室、带一点夸张漫画感。  
视角：2D 俯视，角色是具有强轮廓的几何体、机甲核心、能量球或实验装置。  
色彩：场地使用低饱和冷灰、白、黑、实验绿作为基础，技能使用强色彩区分。  
角色辨识：每个角色拥有固定主色、轮廓形状、拖尾风格和技能特效语言。

### 3.3 叙事语气

轻松、聪明、带一点学术冷幽默。卡牌名可以硬核，但说明必须易懂。

示例：

- “芝诺的悖论”：速度每次只剩一半，所以你永远差一点点撞到我。
- “第三定律”：你推我？很好，现在这份冲量归你了。
- “摩擦系数调参”：把地面从冰面调成橡胶垫。

## 4. 基础对局结构

### 4.1 单局流程

1. 选择角色。
2. 选择卡组，MVP 阶段可固定卡组。
3. 进入竞技场，倒计时 3 秒。
4. 玩家移动、碰撞、抽牌、打牌。
5. 通过地形杀、结构崩坏或计分规则淘汰对手。
6. 结算表现：击飞次数、最大动能、连锁法则、最佳反制。
7. 返回房间或快速再战。

### 4.2 推荐参数

## 5. 核心物理规则

### 5.1 场上实体属性

每个玩家、障碍、临时召唤物都应拥有以下属性。开发时建议数据驱动，方便卡牌直接修改属性。

| 属性 | 含义 | 影响 |
| --- | --- | --- |
| mass | 质量 | 越大越难被击退，撞击别人更强 |
| velocity | 当前速度向量 | 决定移动和撞击动能 |
| angularVelocity | 角速度 | 决定旋转、轨道和扭矩效果 |
| friction | 摩擦系数 | 决定自然减速和刹车距离 |
| restitution | 弹性系数 | 决定碰撞后反弹程度 |
| charge | 电荷 | 正、负、中性三态 |
| stability | 结构稳定性 | 类似生命值 |
| heat | 热量 | 高速碰撞、熵增场会积累 |
| fieldTags | 场状态 | 是否处于引力、泥潭、单维等场 |

### 5.2 伤害与击退

#### 动能伤害

当两个实体或实体与墙体发生高速碰撞时，使用简化动能模型计算伤害：

```text
relativeSpeed = length(vA - vB)
impactEnergy = 0.5 * reducedMass * relativeSpeed^2
damage = clamp((impactEnergy - threshold) * damageScale, 0, maxDamage)
```

设计意图：

- 低速擦碰不造成明显伤害。
- 高速撞墙、被弹射、被电磁脉冲击飞会有高伤害。
- 重型角色不容易被击飞，但高速撞击时也会承担更高风险。

#### 击退冲量

卡牌通常施加冲量，而不是直接位移：

```text
deltaVelocity = impulse / mass
```

设计意图：

- 质量越大，同样冲量下速度变化越小。
- 玩家能通过“质量膨胀”抵抗推力。
- 轻型角色更灵活，但容易被撞飞。

### 5.3 出界判定

场地中央为安全区域，外侧为危险区域。

1. 玩家中心点离开安全边界后，进入“失控区”。
2. 在失控区停留 0.7 秒仍未回场，判定坠落。
3. 如果玩家在失控区使用位移或拉拽技能回到安全区，取消坠落。
4. 被击出场外的玩家由最后一次施加有效冲量的对手获得击飞分。

### 5.4 状态抗性

为了避免控制链过长，玩家连续受到硬控制后获得短暂抗性。

| 状态 | 效果 | 抗性规则 |
| --- | --- | --- |
| 击飞 | 速度被显著改变 | 1.5 秒内再次击飞效果降低 30% |
| 定身 | 速度归零或近似归零 | 4 秒内最多触发 1 次完整定身 |
| 强制吸引 | 向某点持续加速 | 同类吸引叠加时只取最强 |
| 单维锁定 | 只能沿单轴移动 | 离开区域后 2 秒免疫再次锁定 |
| 电荷改写 | 改变正负电荷 | 1 秒内不可被连续翻转 2 次以上 |

## 6. 胜利条件

游戏支持多种胜利规则。MVP 阶段建议只做“地形杀 + 结构崩坏”，完整版逐步加入计分与团队目标。

### 6.1 地形杀

目标：将对手击出竞技场安全边界。

适用模式：

- 1v1 决斗
- 4 人混战
- 2v2 团队战

设计细节：

- 出界后有 0.7 秒挣扎窗口，给“急刹车”“矢量冲刺”“引力牵引”等保命牌发挥空间。
- 击出场外不一定立即结束多人局，而是扣除一条命或给击飞者加分。
- 最后一击归属根据最近 3 秒内施加的有效外向冲量计算。

### 6.2 结构崩坏

目标：把对手稳定性打到 0。

适用模式：

- 有墙场地
- 小地图高频碰撞局
- 新手局，避免频繁坠落挫败

设计细节：

- 稳定性低于 30 时，角色外观出现裂纹、闪烁和不稳定拖尾。
- 稳定性越低，被击飞倍率越高，形成“明星大乱斗式”终结机会。
- 稳定性归零时不是死亡血腥表现，而是“实验代理体解体为粒子”。

### 6.3 实验计分

目标：在限定时间内通过击飞、连锁、控制核心等方式得分。

计分建议：

| 行为 | 分数 |
| --- | --- |
| 击飞对手 | +3 |
| 造成结构崩坏 | +3 |
| 使用 3 张以上卡牌形成连锁击飞 | +1 |
| 用反弹或防守牌反杀 | +1 |
| 占据实验核心 10 秒 | +1 |
| 自己坠落 | -1 |

### 6.4 团队目标

2v2 模式可加入场景目标：

- 把中立能量球撞进对方收集环。
- 抢占引力核心，让对方半场摩擦降低。
- 保护己方“论文终端”，被撞击过多则掉分。

### 6.5 突然死亡

当单局超时且分数相同：

1. 场地安全边界每 10 秒缩小 8%。
2. 所有玩家能量回复提高 50%。
3. 地面摩擦降低，速度更难控制。
4. 30 秒后仍未结束，中央出现强引力井，把所有玩家拉向终结碰撞。

## 7. 角色系统

### 7.1 角色设计原则

每个角色由四部分组成：

- 基础属性：质量、速度、摩擦适应、能量效率、稳定性。
- 被动技能：持续塑造打法。
- 主动技能：短冷却，制造攻防转换。
- 终极技能：高影响力，但需要预判和配合。

属性采用 1-5 星表达，便于玩家理解。

| 属性 | 说明 |
| --- | --- |
| 质量 | 抗击飞能力和撞击威力 |
| 机动 | 起步、转向、回场能力 |
| 控场 | 改变场地或敌人状态的能力 |
| 爆发 | 短时间制造击飞或伤害的能力 |
| 难度 | 上手和精通成本 |

角色关键词：质量、惯性、反作用力、稳定。

基础属性：

| --- | --- |
| 质量 | 5 |
| 机动 | 2 |
| 控场 | 2 |
| 爆发 | 4 |
| 难度 | 2 |

技能：

| 技能 | 类型 | 效果 |
| --- | --- | --- |
| 惯性核心 | 被动 | 自身质量提高 30%，受到小冲量时额外减少 20% 速度变化。 |
| 第三定律 | 主动，冷却 14 秒 | 2 秒内记录第一次来自敌方的冲量，并将 80% 以反方向返还给施加者。若期间未受击，结束时获得一次小型前冲。 |
| 绝对参考系 | 终极，消耗 100 终极能量 | 在自身周围展开 3 秒稳定场。场内友方摩擦提高、受击退降低；敌方进入时速度被校正到较低上限。 |

玩法：

- 适合正面撞击、守边、反制高速角色。
- 用“质量膨胀 + 矢量冲刺”可以打出重锤式撞击。
- 害怕被持续引力场和单维陷阱拉走，因为自身不够灵活。

推荐卡牌：

- 矢量冲刺
- 质量膨胀
- 弹性护盾
- 作用力转移
- 胡克弹簧

设计用途：

- 打乱敌人冲刺路线。
- 制造“螺旋撞击”和混战名场面。

反制方式：

- 降低速度。
- 使用高摩擦或急刹车减少轨迹失控。

## 10. 卡组构建

### 10.1 MVP 固定卡组

每位玩家使用相同 8 张基础牌：

1. 矢量冲刺
2. 急刹车
3. 质量膨胀
4. 弹性护盾
5. 摩擦贴片
6. 正电荷赋予
7. 负电荷赋予
8. 电磁脉冲

目的：

- 降低平衡成本。
- 确保每个玩家都能移动、防守、连招、反制。
- 方便黑客松快速展示。

### 10.2 完整版卡组规则

| 规则 | 建议 |
| --- | --- |
| 卡组数量 | 每套 12 张 |
| 同名牌上限 | 2 张 |
| 高消耗牌上限 | 消耗 5 以上最多 4 张 |
| 防御牌下限 | 至少 2 张 |
| 行动牌下限 | 至少 3 张 |
| 角色专属牌 | 每个角色 2-3 张，可解锁 |

### 10.3 抽牌与循环

建议采用“轻牌库循环”：

- 开局抽 4 张。
- 使用一张后，从牌库抽一张。
- 牌库抽空后，弃牌堆洗回牌库。
- 同一张卡连续使用会有 1 秒全局重复惩罚，避免脚本化连发。

## 11. 连招样例

### 11.1 新手连招

矢量冲刺 -> 撞击敌人 -> 摩擦贴片封回场路线  
用途：简单击退，适合教学。

### 11.2 电磁出界

正电荷赋予敌人 -> 负电荷赋予边缘障碍 -> 敌人被吸向边缘 -> 电磁脉冲翻成排斥出界  
用途：典型铺垫型击杀。

### 11.3 重装反杀

质量膨胀 -> 站在边缘诱敌冲刺 -> 弹性护盾 -> 对手被反弹出界  
用途：艾萨克防反。

### 11.4 引力弹弓

引力井 -> 自己靠近切线方向 -> 角动量守恒 -> 沿切线释放 -> 高速撞击敌人  
用途：高光操作。

### 11.5 芝诺刹车

敌人轻量化冲刺 -> 芝诺的悖论 -> 敌人停在边缘附近 -> 微型白洞或矢量冲刺补刀  
用途：反制高速角色。

### 11.6 单维轨道炮

单维坍缩设定横轴 -> 质量膨胀 -> 矢量冲刺 -> 敌人无法侧向闪避  
用途：强制把空间变成直线决斗。

## 12. 游戏场景策划

### 12.1 场景设计原则

1. 每张地图只突出 1-2 个主要机制，避免信息过载。
2. 场地边缘必须清晰，玩家要能判断危险距离。
3. 场景机制要能和卡牌产生互动，而不是单纯装饰。
4. 地图大小根据人数变化，2 人图不能过大，4 人图需要更多回旋空间。
5. 地图要有“安全区、争夺区、危险区”三层结构。

### 12.2 场景一：无边实验台

定位：新手教学 / 标准竞技场  
人数：2-4  
胜利条件：地形杀 + 结构崩坏  
主题：漂浮在实验院中央的白色圆形平台。

布局：

- 中央圆形安全区。
- 四周无墙，掉落即判出界。
- 中央有一个低强度能量核心，只用于视觉提示，不参与战斗。
- 地面有坐标网格，便于玩家理解方向和速度。

机制：

- 无特殊场地机制。
- 场地边缘会在玩家接近时发出红色警示线。

适合：

- 教学第一关。
- 1v1 平衡测试。
- 展示基础卡牌。

### 12.3 场景二：洛伦兹环形轨道

定位：高速轨道 / 旋转战斗  
人数：2-4  
胜利条件：地形杀  
主题：一个环形粒子加速器平台。

布局：

- 场地为甜甜圈形状，中间和外侧都是坠落区。
- 环道上有 4 段加速磁轨。
- 场地内外侧边缘都有危险提示。

机制：

- 玩家经过加速磁轨时获得沿环形方向的速度。
- 每 20 秒磁轨方向反转。
- 电磁牌在该地图上范围略微增加。

战术：

- 高速角色能绕场积累速度。
- 重型角色可以守住磁轨出口。
- 单维坍缩可以把环形运动打断为直线风险。

### 12.4 场景三：冰面斜坡实验室

定位：低摩擦 / 滑行控制  
人数：2-4  
胜利条件：地形杀 + 计分  
主题：低温摩擦实验区。

布局：

- 场地中央是普通摩擦区。
- 四周有冰面斜坡，通向边缘。
- 角落有少量高摩擦安全垫。

机制：

- 冰面区域摩擦极低，刹车距离变长。
- 每 30 秒冰面扩大一次，突然死亡时覆盖大部分场地。
- 急刹车和摩擦贴片在此地图价值更高。

战术：

- 诱导敌人进入冰面后使用击退。
- 用摩擦贴片制造临时落脚点。
- 芝诺和高斯在该图有较强生存能力。

### 12.5 场景四：双星引力井

定位：引力场 / 轨道弹弓  
人数：2-4  
胜利条件：结构崩坏 + 地形杀  
主题：模拟双星系统的黑暗实验场。

布局：

- 场上有两个缓慢移动的引力核心。
- 核心之间形成危险的潮汐通道。
- 边缘较远，鼓励中场缠斗。

机制：

- 引力核心持续拉扯附近玩家。
- 两个核心靠近时会短暂增强引力。
- 高速撞到核心不会出界，但会受到结构伤害并反弹。

战术：

- 用角动量守恒绕核心弹射。
- 用引力井叠加制造强拉扯。
- 低质量角色风险高，但机动收益也高。

### 12.6 场景五：电容峡谷

定位：电荷管理 / 阵营控制  
人数：2v2 优先，也可 1v1  
胜利条件：计分 + 地形杀  
主题：两侧是巨大电容板的峡谷平台。

布局：

- 左侧墙体带正电，右侧墙体带负电。
- 中央有狭长安全通道。
- 两端有可争夺的接地平台。

机制：

- 带电玩家靠近同极墙会被排斥，靠近异极墙会被吸引。
- 接地平台可以清除电荷，但每次使用后冷却 10 秒。
- 电磁脉冲在峡谷中更容易形成连锁。

战术：

- 麦克斯韦强势，但反制资源也明显。
- 团队可以把敌人挂上电荷后推向墙体。
- 接地平台成为重要争夺点。

### 12.7 场景六：摩擦迷宫

定位：区域摩擦变化 / 路线规划  
人数：2-4  
胜利条件：计分  
主题：不断改变材质的实验地板。

布局：

- 方形场地由多个材质块组成。
- 中央有计分核心。
- 地图边缘不是全部坠落，而是有部分弹性墙。

机制：

- 地板每 15 秒随机改变一批区域的摩擦系数。
- 高摩擦区适合防守，低摩擦区适合加速。
- 玩家可以通过地面颜色预判下一次变化。

战术：

- 控制中央核心比直接击杀更重要。
- 场地牌可以覆盖原有材质，形成小规模安全区。

### 12.8 场景七：单维轨道站

定位：降维 / 直线决斗  
人数：2  
胜利条件：结构崩坏  
主题：由多条移动轨道组成的线性空间。

布局：

- 场地由 3 条平行轨道构成。
- 玩家可在轨道交叉点换线。
- 两端有弹性墙，撞墙造成伤害。

机制：

- 玩家在轨道上主要沿一维移动。
- 特定节点会短暂开放二维自由移动。
- 单维坍缩在该地图升级为“锁定轨道”。

战术：

- 预测和时机比走位更重要。
- 适合做特殊活动模式。

### 12.9 场景八：熵增熔炉

定位：后期压迫 / 热量累积  
人数：4 人混战  
胜利条件：最后存活 / 计分  
主题：热力学实验炉。

布局：

- 圆形平台，外圈周期性升温。
- 中央有冷却核心。
- 四周有旋转热流喷口。

机制：

- 玩家高速移动和撞击会积累热量。
- 热量高会让控制变差，并受到额外结构伤害。
- 中央冷却核心可降低热量，但会成为争夺焦点。

战术：

- 居里强势。
- 高速角色不能无限冲刺，需要管理热量。
- 突然死亡时全场升温，逼迫玩家决战。

## 13. 游戏模式

### 13.1 教学模式

目标：用 5 分钟让玩家理解移动、冲量、摩擦、电荷和出界。

关卡：

1. 用矢量冲刺撞击假人。
2. 从失控区用冲刺回场。
3. 用急刹车停在边缘前。
4. 给两个假人赋予同极电荷并用电磁脉冲推开。
5. 用引力井拉假人撞墙。
6. 完成一次基础击飞。

### 13.2 快速决斗

1v1 标准模式，适合主循环。

规则：

- 三局两胜。
- 每局 180 秒。
- 胜利来自击飞、结构崩坏或时间结束比分领先。

### 13.3 四人混战

规则：

- 每人 3 条命或 5 分钟计分。
- 击飞 +3，自坠 -1。
- 场景事件更频繁。

设计重点：

- 特效不能太乱。
- 同屏卡牌效果需要优先级和清晰边界。

### 13.4 团队实验

2v2 模式。

规则：

- 团队共享分数，不共享血量。
- 可以救援队友，例如用引力井把队友拉回场。
- 友方卡牌默认不造成完整伤害，但仍可能产生位移。

### 13.5 实验室沙盒

单人或多人自定义房间。

功能：

- 选择地图。
- 调整重力、摩擦、能量回复、卡牌冷却。
- 打开轨迹线、力矢量、碰撞数据。
- 适合学习、调试、直播节目效果。

## 14. UI 与交互规划

### 14.1 战斗 HUD

屏幕信息应简洁，不遮挡场地。

必须显示：

- 自己稳定性条。
- 能量条。
- 当前手牌 4 张。
- 角色主动技能冷却。
- 终极能量。
- 自身电荷状态、质量变化、摩擦变化等关键状态。
- 出界倒计时。

建议：

- 手牌放在屏幕底部。
- 能量用分段电池显示。
- 卡牌可用时高亮，不可用时灰显并显示缺少能量。
- 高危状态使用角色周围的环形图标，不堆太多文字。

### 14.2 目标指示

所有需要瞄准的卡牌都应有预览：

- 冲刺牌：显示箭头和预计落点。
- 区域牌：显示圆形/矩形范围。
- 引力牌：显示吸引半径和中心。
- 投影牌：显示线段和投影方向。
- 电磁脉冲：显示范围内带电实体之间的力线。

### 14.3 反馈优先级

玩家最需要看懂的事件按优先级排列：

1. 自己是否即将出界。
2. 自己被什么力影响。
3. 敌人正在释放什么高威胁卡。
4. 自己手牌是否可用。
5. 场地机制下一次变化。

## 15. 音效与手感

### 15.1 音效原则

- 冲量：短促、有方向感。
- 摩擦：刹车声、粒子摩擦声。
- 电磁：高频电流、脉冲爆点。
- 引力：低频吸入、空间弯曲声。
- 数学牌：干净的数字化切片声。
- 出界：夸张但不刺耳的坠落提示。

### 15.2 手感反馈

| 事件 | 反馈 |
| --- | --- |
| 高速撞击 | 屏幕轻震、时间缩放 0.08 秒、冲击波 |
| 被击出边缘 | 边缘警报、角色拖尾变红 |
| 成功反弹 | 清脆音效、护盾闪光 |
| 电磁结算 | 电荷连线先出现，再爆发 |
| 引力坍缩 | 周围粒子向内流动，结束时小爆点 |
| 终极释放 | 角色头像闪光、短暂镜头聚焦 |

## 16. 数值平衡方向

### 16.1 资源平衡

低消耗牌：

- 1-2 能量。
- 用于移动、救场、铺垫。
- 不应单独完成击杀。

中消耗牌：

- 3-4 能量。
- 产生明显控制或防守价值。
- 需要位置配合才强。

高消耗牌：

- 5-7 能量。
- 有机会完成击杀或改变战场。
- 必须有明显预警和反制窗口。

### 16.2 击杀平衡

健康的击杀应该满足至少一个条件：

- 对手站位靠边。
- 施法者提前铺垫了状态。
- 对手交掉了防御牌。
- 施法者承担了风险，例如高速冲向边缘。
- 场景机制创造了窗口。

不健康的击杀：

- 满血满状态在中场被单张牌无预警秒杀。
- 被连续硬控到无法操作。
- 看不见力的来源。
- 不知道应该如何反制。

### 16.3 角色平衡指标

每个角色需要追踪：

- 平均胜率。
- 新手胜率和高手胜率差异。
- 平均击飞数。
- 平均自坠次数。
- 主动技能命中率。
- 终极技能导致击杀比例。
- 被哪些卡牌过度克制。

## 17. 新手引导

### 17.1 教学顺序

1. 先教移动，不讲公式。
2. 再教冲量：箭头越长，推得越猛。
3. 再教质量：重的人不容易飞，但转身慢。
4. 再教摩擦：地面会决定你刹不刹得住。
5. 再教电荷：同极推开，异极吸引。
6. 最后教连招：先改变状态，再用脉冲结算。

### 17.2 术语翻译

游戏内不应直接堆公式，应使用玩家语言。

| 科学术语 | 游戏内表达 |
| --- | --- |
| 冲量 | 推一下 |
| 质量 | 重不重 |
| 摩擦系数 | 滑不滑 |
| 速度向量 | 你正往哪儿冲 |
| 电荷 | 红蓝极性 |
| 引力 | 被吸过去 |
| 角动量 | 绕圈加速 |

## 19. 技术实现建议

### 19.1 推荐技术栈

MVP：

- 渲染与游戏框架：Phaser.js + Matter.js 或 Phaser 内置 Matter。

### 19.2 权威同步建议

- 服务端计算物理结果。
- 客户端做预测和插值。
- 卡牌释放由客户端提交意图，服务端校验能量、冷却、目标。
- 客户端接收状态快照并平滑修正。

MVP 如果时间紧：

- 先做本地双人同屏。
- 再做局域网或简单房间。
- 最后做服务端权威。

## 25. 关键风险与解决方案

| 风险 | 表现 | 解决方案 |
| --- | --- | --- |
| 物理过于混乱 | 玩家看不懂自己为什么飞 | 限制同屏持续场数量，强化力方向视觉 |
| 卡牌过多 | 新手不知道选什么 | 初期固定卡组，逐步解锁 |
| 联机同步困难 | 碰撞结果两端不一致 | 先做服务端权威或本地原型，降低高速极端状态 |
| 强控过多 | 玩家长时间不能操作 | 加控制抗性和挣扎窗口 |
| 科学概念太硬 | 只有懂物理的人会玩 | UI 用玩家语言，详情页再展示公式 |
| 高速角色过强 | 直接秒人 | 热量、摩擦、护盾和芝诺体系反制 |
| 重型角色过强 | 推不动，局面僵硬 | 引力、单维、持续场克制重型 |

## 26. 结语

《力学大乱斗》的核心不是把公式塞进游戏，而是让玩家真的“玩到公式”。当玩家能说出“我先给他挂负电，再把自己变正电，等他靠近边缘时用脉冲把他弹出去”时，这个设计就成立了。

首版最重要的是做出三个体验：

1. 撞击要爽。
2. 法则要看得懂。
3. 连招要让人想再试一次。

只要这三点成立，后续角色、卡牌、地图和模式都可以自然扩展。
