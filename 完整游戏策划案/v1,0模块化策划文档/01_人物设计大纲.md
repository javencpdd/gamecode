# 《力学大乱斗》人物设计大纲

版本：v1.0  
文档定位：角色介绍、属性点、技能设计、角色定位与构筑建议

---

## 1. 人物系统目标

人物系统负责决定玩家的基础打法。卡牌决定“这一局我带什么工具”，人物决定“我天然擅长怎么使用这些工具”。

角色设计目标：

1. 每个角色对应一个清晰科学流派或概念。
2. 每个角色拥有容易理解的优势和弱点。
3. 角色技能与卡牌系统联动，而不是互相割裂。
4. 角色之间有克制关系，但不能形成绝对克制。
5. 新手角色要能直接撞得爽，高手角色要能玩出复杂连锁。

---

## 2. 角色统一模板

每个角色使用以下模板维护。

| 模块 | 说明 |
| --- | --- |
| 角色名 | 游戏内显示名称 |
| 学派/属性 | 角色所属科学主题 |
| 定位 | 例如重型防反、位移刺客、区域控制 |
| 外观关键词 | 主色、形状、特效语言 |
| 属性点 | 质量、机动、控场、爆发、稳定、难度 |
| 被动技能 | 长期塑造打法 |
| 主动技能 | 短冷却技能，战斗中频繁使用 |
| 终极技能 | 高影响力技能，通常需要铺垫 |
| 骰子联动 | 角色如何影响掷骰 |
| 推荐卡组 | 适合该角色的卡牌方向 |
| 克制对象 | 容易压制的角色或流派 |
| 被克制对象 | 容易被压制的角色或流派 |

## 3. 属性点系统

角色属性采用 1-5 星表达，便于玩家快速理解。实际开发中可映射为数值。

| 属性 | 含义 | 影响 |
| --- | --- | --- |
| 质量 | 角色重量和抗击飞能力 | 越高越难被推走，撞击更强，但加速和转向偏慢 |
| 机动 | 位移卡效率、回场能力、惯性修正能力 | 越高越擅长用卡牌改变位置，但不能自由移动 |
| 控场 | 改变区域、方向、状态的能力 | 越高越能限制敌人路线 |
| 爆发 | 短时间制造击飞或伤害的能力 | 越高越容易完成击杀 |
| 稳定 | 抗伤害、抗失衡、容错能力 | 越高越不容易被连招带走 |
| 难度 | 上手和精通成本 | 越高越依赖预判、连招和卡组理解 |

### 3.1 推荐数值映射

| 星级 | 数值倾向 |
| --- | --- |
| 1 | 明显短板 |
| 2 | 偏弱 |
| 3 | 标准 |
| 4 | 优势 |
| 5 | 核心强项 |

### 3.2 派生参数建议

| 参数 | 来源 |
| --- | --- |
| 基础质量 | 质量属性 |
| 位移卡冲量倍率 | 机动属性 |
| 回场卡效率 | 机动 + 稳定修正 |
| 惯性修正能力 | 机动 - 质量修正 |
| 受击飞倍率 | 质量 + 稳定 |
| 结构稳定性 | 稳定 |
| 技能冷却 | 角色定位单独配置 |

## 4. 初始角色

## 4.1 艾萨克

角色全名：艾萨克  
学派/属性：经典力学 / 力学  
定位：重型防反 / 正面冲撞 / 新手友好  
推荐玩家：喜欢正面撞击、防守反击、简单直接打法的玩家。

### 4.1.1 外观设计

主色：蓝色、白色、钢灰色。  
形状：重装方块机甲或带圆角的实验装甲。  
特效：短而厚的直线拖尾，撞击时出现清晰冲击波。  
状态表现：

- 质量膨胀时机甲外壳展开。
- 第三定律触发时外壳出现反向力箭头。
- 终极技能开启时脚下出现稳定参考系网格。

### 4.1.2 属性点

| 属性 | 星级 |
| --- | --- |
| 质量 | 5 |
| 机动 | 2 |
| 控场 | 2 |
| 爆发 | 4 |
| 稳定 | 5 |
| 难度 | 2 |

### 4.1.3 被动技能：惯性核心

效果：

- 自身基础质量提高 30%。
- 受到小冲量时额外减少 20% 速度变化。
- 当自身速度低于一定阈值时，抗击飞能力额外提高。

设计目的：

- 让艾萨克成为最稳的角色。
- 鼓励玩家守边、卡位、正面碰撞。

注意：

- 不能让艾萨克完全推不动。
- 引力、单维、持续场仍应能有效限制他。

### 4.1.4 主动技能：第三定律

冷却：14 秒  
持续：2 秒  
类型：防反

效果：

- 开启后记录第一次来自敌方的有效冲量。
- 将该冲量的 80% 按反方向返还给施加者。
- 若期间没有受到有效冲量，技能结束时艾萨克获得一次小型前冲。

骰子联动：

- 若技能期间触发反弹，可掷力学骰。
- 1-2 点：返还 65% 冲量。
- 3-4 点：返还 80% 冲量。
- 5 点：返还 95% 冲量。
- 6 点：返还 100% 冲量，并让攻击者短暂失衡。

### 4.1.5 终极技能：绝对参考系

终极能量：100  
持续：3 秒  
类型：区域稳定

效果：

- 以自身为中心展开稳定场。
- 场内友方受击退降低，摩擦提高。
- 场内敌方速度上限降低，冲刺距离缩短。
- 稳定场不会直接造成伤害，主要用于反打和守边。

### 4.1.6 推荐卡组

基础卡：

- 矢量冲刺
- 急刹车
- 弹性护盾
- 直线撞锤
- 冲量缓冲

属性卡：

- 质量膨胀
- 第三定律
- 碰撞放大器
- 胡克弹簧
- 静摩擦极限

特殊卡：

- 经典校准
- 牛顿摆

### 4.1.7 克制关系

擅长对抗：

- 高速直线冲刺角色。
- 依赖正面撞击的力学流派。
- 低质量脆皮角色。

害怕：

- 引力持续拉扯。
- 数学降维和投影。
- 电学远程铺垫后爆发。

## 4.2 麦克斯韦

角色全名：麦克斯韦  
学派/属性：电磁学 / 电学  
定位：电荷连锁 / 高位移爆发 / 中高难度  
推荐玩家：喜欢提前铺垫、连锁爆发、把敌人吸来弹去的玩家。

### 4.2.1 外观设计

主色：黄色、蓝色、红色。  
形状：电磁球体或轻型悬浮核心。  
特效：正负电荷粒子环绕，释放技能时出现电场线。  
状态表现：

- 正电荷状态显示红色加号环。
- 负电荷状态显示蓝色减号环。
- 过载时全身电弧增强。

### 4.2.2 属性点

| 属性 | 星级 |
| --- | --- |
| 质量 | 2 |
| 机动 | 5 |
| 控场 | 4 |
| 爆发 | 4 |
| 稳定 | 2 |
| 难度 | 4 |

### 4.2.3 被动技能：电荷亲和

效果：

- 场上每存在一个带电实体，自身位移卡产生的速度变化提高 3%。
- 最高叠加到 15%。
- 如果场上同时存在正负电荷，自身电学卡瞄准预览线更长。

### 4.2.4 主动技能：极性翻转

冷却：12 秒  
类型：状态改写

效果：

- 翻转指定目标的电荷。
- 如果目标原本没有电荷，则随机赋予正或负电荷。
- 翻转后立即产生一次小型吸引或排斥。

骰子联动：

- 掷电学骰。
- 点数越高，翻转附带的小冲量越强。
- 6 点时，翻转效果会扩散到目标附近一个带电实体。

### 4.2.5 终极技能：麦克斯韦方程组

终极能量：100  
持续：4 秒  
类型：全场电磁结算

效果：

- 场上所有带电实体之间出现可见电场线。
- 持续期间电荷之间产生轻微吸引/排斥。
- 技能结束时结算一次强电磁脉冲。
- 同极排斥，异极吸引。

### 4.2.6 推荐卡组

基础卡：

- 矢量冲刺
- 边缘跳跃
- 紧急接地
- 实验预案

属性卡：

- 正电荷赋予
- 负电荷赋予
- 电磁脉冲
- 导体地板
- 电荷复制
- 放电链

特殊卡：

- 电荷筛选
- 方程共振

### 4.2.7 克制关系

擅长对抗：

- 低位移效率的重型角色。
- 喜欢站边防守的角色。
- 不带接地和绝缘的卡组。

害怕：

- 艾萨克这类高质量防反角色。
- 接地、绝缘、电磁静默。
- 突脸后持续贴身压制。

## 4.3 芝诺

角色全名：芝诺  
学派/属性：概念数学 / 数学  
定位：闪避控制 / 速度削弱 / 高技巧游击  
推荐玩家：喜欢骗技能、控节奏、用规则让敌人打空的玩家。

### 4.3.1 外观设计

主色：绿色、青色、黑色。  
形状：几何乌龟、低多边形残影体或分段运动核心。  
特效：移动时留下等距残影，技能触发时轨迹被切成一段一段。  
状态表现：

- 减半效果显示不断缩短的速度箭头。
- 空间折叠时显示折线坐标。
- 终极技能让目标拖尾变成分段虚线。

### 4.3.2 属性点

| 属性 | 星级 |
| --- | --- |
| 质量 | 2 |
| 机动 | 4 |
| 控场 | 5 |
| 爆发 | 2 |
| 稳定 | 3 |
| 难度 | 5 |

### 4.3.3 被动技能：半程残影

效果：

- 每隔 8 秒，下一次受到的强击退会被拆成两段。
- 第一段立即生效，第二段延迟 0.5 秒生效。
- 延迟期间玩家可以使用卡牌或技能尝试回场。

### 4.3.4 主动技能：空间折叠

冷却：16 秒  
类型：短距离位移

效果：

- 短距离闪现到指定位置。
- 闪现后留下残影，持续 0.5 秒。
- 敌人撞到残影会被轻微减速。

骰子联动：

- 掷数学骰。
- 点数越高，残影持续越久。
- 6 点时残影会额外触发一次“速度减半”小效果。

### 4.3.5 终极技能：芝诺的终点

终极能量：100  
持续：3 秒  
类型：强控反制

效果：

- 指定一个敌人，使其速度每 0.5 秒降低到当前的 60%。
- 目标不会被完全定身，仍可通过卡牌产生低速位移和出牌。
- 如果目标在期间撞墙或出界边缘，会受到额外结构伤害。

### 4.3.6 推荐卡组

基础卡：

- 急刹车
- 坐标平移
- 稳定实验
- 轨迹修正

属性卡：

- 芝诺的悖论
- 单维坍缩
- 投影线
- 向量消元
- 函数拟合

特殊卡：

- 无限细分
- 终点不存在

### 4.3.7 克制关系

擅长对抗：

- 高速冲刺角色。
- 依赖精确撞击的角色。
- 技能前摇明显的爆发卡组。

害怕：

- 大范围区域压制。
- 低成本持续消耗。
- 不依赖速度的状态伤害。

## 5. 扩展角色

## 5.1 居里

学派/属性：热学 / 放射与热量  
定位：区域污染 / 持续压制 / 团队辅助

属性点：

| 属性 | 星级 |
| --- | --- |
| 质量 | 3 |
| 机动 | 3 |
| 控场 | 5 |
| 爆发 | 2 |
| 稳定 | 3 |
| 难度 | 3 |

被动：半衰期

- 自己施加的负面区域持续时间提高。
- 区域效果会随时间逐渐衰减。

主动：放射云室

- 在指定区域生成云室。
- 敌人进入后热量上升，轨迹暴露。
- 掷热学骰决定区域半径。

终极：链式衰变

- 引爆所有带热量的敌人。
- 热量越高，受到的冲量和结构伤害越高。

推荐卡：

- 熵增领域
- 热传导
- 蒸汽爆发
- 绝热护层
- 热机循环

---

## 5.2 诺特

学派/属性：守恒律 / 力学与数学  
定位：资源回收 / 动量转移 / 反击辅助

属性点：

| 属性 | 星级 |
| --- | --- |
| 质量 | 3 |
| 机动 | 3 |
| 控场 | 3 |
| 爆发 | 4 |
| 稳定 | 4 |
| 难度 | 4 |

被动：能量回收

- 自身受到碰撞后，根据碰撞强度恢复少量能量。
- 触发有冷却，避免故意刷能量。

主动：动量转账

- 选中两个目标，将第一个目标的一部分速度向量转移给第二个目标。
- 可用于把敌人的冲刺转移给障碍或队友。

终极：对称性破缺

- 在目标区域制造不对称守恒场。
- 敌方惯性修正和位移卡转向效果下降。
- 友方下一次冲刺消耗降低。

推荐卡：

- 动量交换
- 动能回收
- 向量消元
- 归一化
- 第三定律

## 5.3 洛伦兹

学派/属性：电磁与旋转  
定位：高速弧线 / 轨道突袭 / 高难度刺客

属性点：

| 属性 | 星级 |
| --- | --- |
| 质量 | 2 |
| 机动 | 5 |
| 控场 | 3 |
| 爆发 | 4 |
| 稳定 | 2 |
| 难度 | 5 |

被动：侧向偏折

- 高速滑行或使用位移卡后获得额外横向偏转能力。
- 速度越高，卡牌造成的弧线轨迹越明显。

主动：洛伦兹漂移

- 获得一段弧形加速。
- 路径末端撞击敌人时造成旋转击退。

终极：螺旋参照系

- 以自身为中心生成旋转参考系。
- 区域内直线速度会被偏转成弧线。

推荐卡：

- 矩阵旋转
- 多维扭矩
- 磁轨加速
- 切线加速
- 角动量守恒

## 5.4 高斯

学派/属性：几何与数学  
定位：屏障控制 / 路线规划 / 团队控场

属性点：

| 属性 | 星级 |
| --- | --- |
| 质量 | 3 |
| 机动 | 2 |
| 控场 | 5 |
| 爆发 | 2 |
| 稳定 | 4 |
| 难度 | 4 |

被动：曲率感知

- 靠近场地边缘时获得更明显的边界提示。

主动：坐标投影

## 5.5 图灵

学派/属性：计算与概率  
定位：预测模拟 / 手牌操控 / 策略控制

属性点：

| 属性 | 星级 |
| --- | --- |
| 质量 | 2 |
| 机动 | 3 |
| 控场 | 4 |
| 爆发 | 3 |
| 稳定 | 3 |
| 难度 | 5 |

被动：预测缓存

- 每隔一段时间显示敌方下一张可能使用的卡牌类别。
- 不显示具体卡名，避免过强。

主动：延迟执行

- 本次打出的卡牌不会立即生效。
- 1.5 秒后自动触发。
- 可制造夹击和心理压力。

终极：停机问题

- 指定区域内敌方下一次出牌有概率延迟。
- 若延迟期间被撞击，卡牌取消并返还一半能量。

推荐卡：

- 函数拟合
- 实验预案
- 重整手牌
- 概率坍缩
- 递归复制

## 7. 角色平衡指标

每个版本测试时记录：

1. 胜率。
2. 新手胜率。
3. 高手胜率。
4. 平均击飞数。
5. 平均自坠次数。
6. 主动技能命中率。
7. 终极技能造成击杀比例。
8. 常用卡组。
9. 最常被哪些卡牌克制。
10. 是否存在不可反制连招。

## 8. 后续新增角色原则

新增角色前先回答：

1. 这个角色对应什么科学概念？
2. 它与已有角色的核心差异是什么？
3. 它是否需要新规则？如果需要，是否值得？
4. 它的弱点是否清楚？
