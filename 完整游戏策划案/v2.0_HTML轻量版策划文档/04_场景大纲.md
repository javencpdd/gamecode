# 《力学大乱斗》场景大纲

版本：v2.0  
文档定位：地图主题、场景机制、交互元素、地图优先级与美术方向

---

## 1. 场景设计目标

《力学大乱斗》的场景不是普通背景，而是战斗规则的一部分。每张地图都应该提供一种独特的物理问题，让玩家用角色和卡牌去解决。

场景设计目标：

1. 每张地图有 1-2 个核心机制。
2. 场景机制能与卡牌产生连锁。
3. 地图边界和危险区域必须清晰。
4. 新手地图要干净，进阶地图再增加复杂机制。
5. 场景不能抢走卡牌和角色的主体地位。
6. v2.0 HTML 首版地图必须能用 Canvas 几何图形和少量参数绘制，不依赖大背景图。

---

## 2. 场景基础结构

每张地图由三层区域组成。

| 区域 | 作用 |
| --- | --- |
| 安全区 | 玩家主要战斗区域 |
| 争夺区 | 有资源、核心、机关或位置优势 |
| 危险区 | 边缘、坠落、激光、强引力、热区等 |

### 2.1 地图字段模板

| 字段 | 说明 |
| --- | --- |
| 地图名 | 游戏内显示名称 |
| 主题 | 实验室、粒子轨道、冰面、熔炉等 |
| 推荐人数 | 1v1 / 2v2 / 4 人混战 |
| 胜利方式 | 地形杀、结构崩坏、计分、目标 |
| 核心机制 | 地图最重要的规则 |
| 交互元素 | 可撞击、可争夺、可触发的对象 |
| 推荐卡牌 | 在该地图特别有用的卡牌 |
| 风险点 | 可能造成不公平或视觉混乱的地方 |
| 美术关键词 | 颜色、材质、特效 |

## 4. 首发地图

## 4.1 无边实验台

定位：标准地图 / 新手教学 / 平衡测试  
推荐人数：2-4  
胜利方式：地形杀 + 结构崩坏  
优先级：P0

### 4.1.1 场景概念

漂浮在范式实验院中央的基础竞技平台。地面是白色实验台，带有淡灰色坐标网格。四周没有实体墙，玩家被击出边缘后会坠入实验缓冲区。

### 4.1.2 地图布局

- 圆形或八边形主平台。
- 中央为开阔安全区。
- 四周边缘有红色警示线。
- 无额外机关。
- 可在中央放置一个无碰撞实验核心作为视觉中心。

### 4.1.3 核心机制

无特殊机制，强调基础物理、卡牌和地形杀。

### 4.1.4 交互元素

| 元素 | 说明 |
| --- | --- |
| 安全边界 | 玩家越界后进入失控区 |
| 边缘警示线 | 玩家靠近时变亮 |
| 坐标网格 | 帮助玩家理解方向和速度 |

### 4.1.5 推荐卡牌

- 矢量冲刺
- 急刹车
- 回场抓钩
- 弹性护盾
- 质量膨胀
- 电磁脉冲

### 4.1.6 美术关键词

白色实验台、蓝色网格、红色边缘、干净明亮、低干扰。

---

## 4.2 冰面斜坡实验室

定位：低摩擦地图 / 滑行控制  
推荐人数：2-4  
胜利方式：地形杀 + 计分  
优先级：P0

### 4.2.1 场景概念

低温摩擦实验室。场地周围铺设大面积冰面，玩家在边缘区域更难刹车，容易被诱导滑出平台。

### 4.2.2 地图布局

- 中央为普通摩擦区。
- 四周为低摩擦冰面。
- 四个角落有高摩擦安全垫。
- 外侧无墙，保留地形杀。

### 4.2.3 核心机制

| 机制 | 说明 |
| --- | --- |
| 低摩擦冰面 | 自然减速降低，刹车距离变长 |
| 冰面扩张 | 每 30 秒冰面向中央扩大 |
| 安全垫 | 高摩擦区域，可用于回场和防守 |

### 4.2.4 推荐卡牌

- 急刹车
- 摩擦贴片
- 冰面涂层
- 回场抓钩
- 芝诺的悖论
- 投影线

### 4.2.5 风险点

- 新手可能连续滑出场外。
- 需要明显显示摩擦区域。
- 冰面颜色不能和电学、数学特效混淆。

### 4.2.6 美术关键词

浅蓝冰面、白色雾气、低温灯光、地面反光、刹车冰屑。

---

## 4.3 电容峡谷

定位：电荷机制地图 / 2v2 推荐  
推荐人数：2v2 / 1v1  
胜利方式：计分 + 地形杀  
优先级：P1

### 4.3.1 场景概念

两侧是巨大电容板的狭长实验峡谷。左侧墙体带正电，右侧墙体带负电。带电玩家靠近墙体时会受到吸引或排斥。

### 4.3.2 地图布局

- 狭长矩形平台。
- 左墙正电，右墙负电。
- 中央有较宽通道。
- 两端有接地平台。
- 边缘局部开放，可地形杀。

### 4.3.3 核心机制

| 机制 | 说明 |
| --- | --- |
| 带电墙体 | 根据玩家电荷产生吸引或排斥 |
| 接地平台 | 清除电荷，使用后冷却 |
| 导体区域 | 电学卡范围略微扩大 |

### 4.3.4 推荐卡牌

- 正电荷赋予
- 负电荷赋予
- 极性翻转
- 电磁脉冲
- 接地
- 绝缘涂层
- 导体地板

### 4.3.5 风险点

- 电荷关系必须清晰显示。
- 需要避免玩家被墙体无限吸住。
- 接地平台位置要公平。

### 4.3.6 美术关键词

红蓝电容板、电弧、金属峡谷、接地符号、强对比电场线。

---

## 4.4 双星引力井

定位：引力地图 / 轨道弹弓  
推荐人数：2-4  
胜利方式：结构崩坏 + 地形杀  
优先级：P1

### 4.4.1 场景概念

模拟双星系统的暗色实验场。两个引力核心在地图上缓慢移动，玩家可以被它们吸引，也可以利用它们进行轨道加速。

### 4.4.2 地图布局

- 圆形或椭圆形主平台。
- 两个引力核心绕中央缓慢运动。
- 中央区域为高风险潮汐通道。
- 边缘较宽，鼓励中场缠斗。

### 4.4.3 核心机制

| 机制 | 说明 |
| --- | --- |
| 引力核心 | 持续吸引附近实体 |
| 双星靠近 | 两个核心靠近时引力增强 |
| 核心反弹 | 撞到核心会受到结构伤害并反弹 |
| 轨道窗口 | 特定距离可进入稳定绕行 |

### 4.4.4 推荐卡牌

- 引力井
- 角动量守恒
- 逃逸速度
- 近地点加速
- 投影线
- 急刹车

### 4.4.5 风险点

- 引力太强会让玩家失去控制感。
- 需要清晰显示引力半径。
- 多个引力场叠加要限制强度。

### 4.4.6 美术关键词

深蓝宇宙、弯曲网格、发光核心、环形粒子流、低频震动。

## 5. 扩展地图

## 5.1 洛伦兹环形轨道

定位：高速旋转地图 / 粒子加速器  
推荐人数：2-4  
胜利方式：地形杀  
优先级：P2

布局：

- 甜甜圈形平台。
- 中央洞和外侧都可坠落。
- 环道上有 4 段磁轨。

机制：

- 玩家经过磁轨时获得环向加速。
- 磁轨方向每 20 秒反转。
- 高速状态下转向更难。

推荐卡牌：

- 磁轨加速
- 矩阵旋转
- 多维扭矩
- 急刹车
- 回场抓钩

---

## 5.2 摩擦迷宫

定位：材质变化 / 路线规划  
推荐人数：2-4  
胜利方式：计分  
优先级：P2

布局：

- 方形地图分割为多个地板块。
- 中央有计分核心。
- 边缘部分有弹性墙，部分开放。

机制：

- 地板每 15 秒改变摩擦属性。
- 不同颜色表示高摩擦、低摩擦、普通。
- 玩家可以用场地卡覆盖局部地板。

推荐卡牌：

- 摩擦贴片
- 冰面涂层
- 减速区
- 加速带
- 函数拟合

---

## 5.3 单维轨道站

定位：数学地图 / 降维玩法  
推荐人数：2  
胜利方式：结构崩坏  
优先级：P2

布局：

- 三条平行轨道。
- 轨道交叉点可换线。
- 两端有弹性墙。

机制：

- 玩家默认沿轨道运动。
- 特定节点短暂开放二维位移结算，让位移卡可以选择任意方向。
- 单维坍缩在此地图强化为锁定轨道。

推荐卡牌：

- 单维坍缩
- 投影线
- 坐标平移
- 向量消元
- 直线撞锤

---

## 5.4 熵增熔炉

定位：热量地图 / 后期压迫  
推荐人数：4 人混战  
胜利方式：最后存活 / 计分  
优先级：P2

布局：

- 圆形平台。
- 外圈周期升温。
- 中央有冷却核心。
- 四周有旋转热流喷口。

机制：

- 高速位移和撞击会积累热量。
- 热量高时转向变差，受到额外伤害。
- 中央冷却核心可降低热量。
- 突然死亡时全场升温。

推荐卡牌：

- 急速冷却
- 熵增领域
- 热传导
- 蒸汽爆发
- 绝热护层

---

## 5.5 棱镜观测室

定位：光学地图 / 视觉误导  
推荐人数：2-4  
胜利方式：计分 + 结构崩坏  
优先级：P3

布局：

- 多块可旋转镜面。
- 中央有棱镜核心。
- 地图边缘有激光边界。

机制：

- 轨迹预览线穿过棱镜区会折射。
- 镜面可反弹部分冲击波或投射效果。
- 棱镜核心周期性发出眩光。

推荐卡牌：

- 反射镜面
- 折射棱镜
- 眩光闪烁
- 镜像分身
- 激光边界

---

## 5.6 拓扑折叠场

定位：空间门地图 / 高级位移规划  
推荐人数：2v2 / 4 人  
胜利方式：计分  
优先级：P3

布局：

- 中央开放。
- 四角有空间门。
- 边缘存在局部坠落区。

机制：

- 进入一处空间门会从另一处出来。
- 空间门配对每 40 秒改变。
- 高速进入空间门会保留部分速度。

推荐卡牌：

- 拓扑隧道
- 坐标反演
- 函数拟合
- 回场抓钩
- 矢量冲刺

## 8. 场景视觉规则

### 8.1 危险层级

| 危险等级 | 表现 |
| --- | --- |
| 低危 | 黄色提示线 |
| 中危 | 橙色脉冲边框 |
| 高危 | 红色闪烁、警报音、屏幕边缘提示 |

### 8.2 地面材质颜色

| 材质 | 建议颜色 |
| --- | --- |
| 普通地面 | 白灰、浅蓝灰 |
| 高摩擦 | 深灰、橡胶纹理 |
| 低摩擦 | 浅蓝、反光 |
| 带电 | 红/蓝电路纹理 |
| 热区 | 橙红、热浪 |
| 引力区 | 深蓝、弯曲网格 |
| 数学区 | 绿色坐标线 |
| 光学区 | 彩色折射边缘 |

### 8.3 可读性要求

- 地图特效不能盖住角色状态。
- 边界必须比背景更醒目。
- 场地机制启动前至少 1 秒预警。
- 重要地图物件要有固定轮廓和颜色。

### 8.4 v2.0 轻量场景素材规则

为了控制 HTML 文件体积：

- 地图背景优先用 Canvas 绘制网格、边界、区域色块。
- 不使用大尺寸背景图片。
- 场地材质通过颜色、透明度、线条纹理表示。
- 粒子数量设置上限，离屏或生命周期结束立即回收。
- 多张地图尽量复用同一套绘制函数，只替换参数。

首版地图数据建议：

```js
{
  id: "lab_table",
  shape: "circle",
  radius: 360,
  zones: [
    { type: "normal", radius: 260 },
    { type: "dangerEdge", radius: 350 }
  ]
}
```

## 9. 地图平衡指标

每张地图测试时记录：

1. 平均单局时长。
2. 地形杀占比。
3. 结构崩坏占比。
4. 自坠次数。
5. 哪些角色胜率过高。
6. 哪些卡牌在该图过强。
7. 玩家是否看得懂地图机制。
8. 机制是否导致长时间无法操作。
9. 地图是否存在明显卡死点。
10. 多人局中特效是否过于混乱。

---

## 10. 新地图设计原则

新增地图前先回答：

1. 这张地图的核心物理问题是什么？
2. 它鼓励什么打法？
3. 它克制什么打法？
4. 它和哪些卡牌自然联动？
5. 它是否有新手可理解的视觉规则？
6. 机制失败时玩家是否能知道原因？
7. 这张地图是否真的与已有地图不同？

如果一张地图只是换皮，没有改变战斗决策，不建议加入正式地图池。
