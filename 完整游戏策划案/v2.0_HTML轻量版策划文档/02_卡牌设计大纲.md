# 《力学大乱斗》卡牌设计大纲

版本：v2.0  
文档定位：卡牌分类、骰子规则、基础卡、属性卡、特殊卡、卡组构筑

---

## 1. 卡牌系统目标

卡牌系统是《力学大乱斗》的核心策略层。角色决定玩家擅长什么，场景决定战斗环境，卡牌决定玩家每一次如何改变物理规则。

卡牌系统要实现：

1. 基础卡保证每个玩家都能通过卡牌产生位移、防守、回场、攻击。
2. 属性卡提供不同科学流派的构筑方向。
3. 特殊卡提供高风险、高随机、角色专属和场景限定玩法。
4. 掷骰增加实验随机性，但不能破坏公平。
5. 每张卡都要能被视觉化，让玩家知道发生了什么。
6. v2.0 需要控制卡牌数量、图标数量和规则复杂度，优先用文字、颜色、简单图标和程序特效表现卡牌。

---

## 1.1 v2.0 轻量卡牌原则

面向 HTML 小游戏时，卡牌设计要兼顾可玩性和文件体积。

原则：

- 首版不追求大牌池，优先保证 18-24 张卡足够好玩。
- 卡牌图标优先使用文字、CSS、emoji 禁用或少用、Canvas 简笔符号、内联 SVG。
- 首版只实现标准 D6，属性骰先作为颜色和分类表现。
- 卡牌数据集中维护，避免为每张卡写大量独立逻辑。
- 多张卡复用同一批效果函数，如 `applyImpulse`、`spawnZone`、`addStatus`、`rollDice`。
- 延时和持续卡首版控制在 4-6 张，避免 UI 和计时系统过重。

## 2. 卡牌总分类

| 大类 | 子类 | 作用 |
| --- | --- | --- |
| 基础卡 | 位移、防御、攻击、场地、资源 | 所有角色都能使用，构成游戏基本操作 |
| 属性卡 | 力学、电学、数学、引力、热学、光学等 | 构成流派和连招核心 |
| 特殊卡 | 角色专属、概率、量子、场景限定、终极卡 | 提供独特构筑和娱乐变化 |

### 2.1 基础卡

基础卡特点：

- 易懂。
- 消耗较低。
- 不依赖复杂前置状态。
- 所有角色可用。
- 是新手教学的主要卡牌。

### 2.2 属性卡

属性卡特点：

- 绑定一个科学属性。
- 通常需要与状态、场地或其他卡牌配合。
- 构成卡组主要风格。
- 适合进阶构筑。

### 2.3 特殊卡

特殊卡特点：

- 规则更特殊。
- 风险或限制更明显。
- 可能绑定角色、地图、模式或稀有度。
- 不建议一开始开放太多。

## 3. 卡牌字段模板

每张卡牌建议使用统一字段维护。

| 字段 | 说明 |
| --- | --- |
| 卡牌名 | 游戏内显示名称 |
| 大类 | 基础卡 / 属性卡 / 特殊卡 |
| 子类 | 位移、防御、力学、电学等 |
| 消耗 | 使用所需能量 |
| 骰子 | 无 / D6 / 属性骰 / 混沌骰 |
| 目标 | 自身、方向、敌人、地点、区域、全场 |
| 生效方式 | 瞬发、持续、延迟、结算、对抗 |
| 计时方式 | 立即、延时、持续 N 个节拍、持续 N 回合 |
| 保底效果 | 掷低点也会发生的基本效果 |
| 高点效果 | 掷高点时增强的部分 |
| 反制方式 | 敌方如何应对 |
| 视觉表现 | 特效、轨迹、状态图标 |
| 优先级 | P0 / P1 / P2 |

## 3.1 卡牌生效时机

为了加入延时技能和持续多回合效果，卡牌按生效时机再增加一层标签。

| 时机标签 | 说明 | 示例 |
| --- | --- | --- |
| 瞬发 | 使用后立刻结算 | 矢量冲刺、接地 |
| 持续 | 使用后持续若干秒或若干节拍 | 摩擦贴片、引力井 |
| 延时 | 使用后先进入倒计时，结束后触发 | 延时冲量、坍缩预告 |
| 准备 | 使用后挂在自己身上，满足条件时触发 | 预载护盾、反应实验 |
| 维持 | 每个战斗节拍消耗资源来延长 | 电荷维持、惯性协议 |
| 回合持续 | 在回合制或桌游模式中持续多个回合 | 熵增记录、递归证明 |

实时模式中，“回合持续”可换算为“战斗节拍”。建议一个战斗节拍为 5 秒。  
桌游模式中，“回合持续”就是玩家行动轮次。

## 4. 骰子系统

### 4.1 核心规则

掷骰用于模拟实验误差和临场变化。大多数卡牌采用“保底效果 + 骰子强化”。

标准 D6：

| 点数 | 名称 | 含义 |
| --- | --- | --- |
| 1 | 失准 | 保底效果，强度较低，可能有轻微副作用 |
| 2 | 普通 | 接近标准效果 |
| 3 | 稳定 | 标准效果 |
| 4 | 强化 | 效果小幅提高 |
| 5 | 优势 | 效果明显提高或附加小效果 |
| 6 | 暴击实验 | 强化效果并触发额外特效 |

### 4.2 推荐倍率

| 点数 | 倍率 |
| --- | --- |
| 1 | 0.75 |
| 2 | 0.9 |
| 3 | 1.0 |
| 4 | 1.15 |
| 5 | 1.3 |
| 6 | 1.5 + 附加效果 |

### 4.3 骰子类型

| 骰子 | 用途 |
| --- | --- |
| D6 标准骰 | 基础卡与通用属性卡 |
| MD6 力学骰 | 质量、冲量、碰撞、动量 |
| ED6 电学骰 | 电荷、脉冲、导体、极性 |
| XD6 数学骰 | 投影、减半、降维、坐标变化 |
| GD6 引力骰 | 引力井、轨道、潮汐、逃逸 |
| TD6 热学骰 | 热量、熵增、冷却、热膨胀 |
| LD6 光学骰 | 折射、反射、镜像、眩光 |
| CD6 混沌骰 | 高风险概率牌和量子牌 |

v2.0 首版实际实现建议：

- 只做 D6 标准骰。
- 力学、电学、数学骰先不做独立概率，只用颜色区分。
- 混沌骰留到 Demo 或娱乐模式。

### 4.4 骰子修正规则

骰子结果可以被修正，但最终限制在 1-6。

修正来源：

- 角色被动。
- 属性场景。
- 资源卡。
- 连锁条件。
- 负面状态。

示例：

- 麦克斯韦场上带电实体不少于 3 个时，电学骰 +1。
- 艾萨克掷力学骰出 1 时，可视为 2。
- “稳定实验”使下一次骰子最低视为 3。

### 4.5 防止随机性失控

1. 防御牌不能因为掷 1 而完全无效。
2. 6 点只能触发一次额外效果，不允许无限连锁。
3. 连续两次掷 1 后，下一次最低视为 3。
4. 排位模式限制混沌骰卡数量。
5. 高风险卡必须在卡面写清楚副作用。

## 5. 基础卡

基础卡分为五类：位移、防御、通用攻击、场地、资源。

## 5.1 位移基础卡

位移基础卡是本游戏最重要的基础卡类型。由于玩家不能通过摇杆、WASD 或方向键自由移动，所有主动位置变化都必须由这类卡牌、角色技能或场景机制产生。

| 卡牌 | 消耗 | 骰子 | 效果 | 优先级 |
| --- | --- | --- | --- | --- |
| 矢量冲刺 | 2 | 强度 D6 | 向瞄准方向施加冲量 | P0 |
| 短程微调 | 1 | 无 | 小幅改变速度方向 | P1 |
| 回场抓钩 | 3 | 范围 D6 | 向安全区边缘拉回自身 | P0 |
| 反冲滑步 | 2 | 强度 D6 | 后退并向前打出小冲击 | P1 |
| 轨迹修正 | 1 | 无 | 削弱横向速度，让路线更可控 | P1 |
| 二段推进 | 3 | 强度 D6 | 短时间内连续冲刺两次 | P1 |
| 惯性漂移 | 2 | 持续 D6 | 转向半径变小，适合高速弧线 | P2 |
| 边缘跳跃 | 2 | 无 | 仅失控区可用，获得一次回场位移 | P0 |

### 常驻基础指令卡

为了避免玩家因手牌随机而完全无法改变位置，每名玩家拥有 2 张不进入牌库的常驻基础指令卡。它们仍然是卡牌，有能量消耗和冷却，不属于自由移动。

| 卡牌 | 消耗 | 冷却 | 效果 | 定位 |
| --- | --- | --- | --- | --- |
| 微型推进 | 1 | 3 秒 | 向瞄准方向施加小冲量 | 最低限度位移 |
| 紧急制动 | 1 | 5 秒 | 短时间提高摩擦并降低当前速度 | 最低限度防坠 |

限制：

- 常驻基础指令卡不能放入卡组，也不能被复制。
- 常驻基础指令卡强度低于同类手牌。
- 使用时必须有卡牌释放动画、能量扣除和冷却提示。

### 矢量冲刺详细设计

消耗：2  
目标：方向  
生效：瞬发  
保底：向目标方向冲刺。  
高点：冲量增加，6 点时冲刺末端产生小冲击波。  
反制：急刹车、弹性护盾、预判躲避。  
视觉：箭头预览、角色拖尾、落点冲击线。

## 5.6 延时与持续基础卡

这类卡牌不绑定属性，主要用于教学“预判”和“持续经营”。它们适合让玩家学会提前布置，而不是只靠即时反应。

| 卡牌 | 消耗 | 骰子 | 计时 | 效果 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| 延时冲量 | 2 | 强度 D6 | 延时 1.5 秒 | 在自身当前位置生成倒计时箭头，到时向箭头方向爆发推力 | P1 |
| 预载护盾 | 3 | 持续 D6 | 准备 1 个节拍 | 受到下一次撞击时自动展开护盾 | P1 |
| 定时震荡波 | 4 | 范围 D6 | 延时 2 秒 | 倒计时结束后释放圆形击退波 | P1 |
| 惯性预约 | 2 | 无 | 准备 1 个节拍 | 下一个节拍开始时，保留当前速度并获得短暂抗减速 | P2 |
| 后发制动 | 2 | 持续 D6 | 持续 2 个节拍 | 每个节拍开始时小幅降低自身速度，适合防止滑出场外 | P1 |
| 保险抓钩 | 3 | D6 | 准备 2 个节拍 | 若期间进入失控区，自动向安全区发射抓钩 | P0 |
| 延迟抽牌 | 0 | 无 | 延时 1 个节拍 | 现在不抽牌，下个节拍抽 2 张并弃 1 张 | P1 |
| 持续校准 | 2 | 无 | 持续 3 个节拍 | 每个节拍第一次掷骰最低视为 2；最后一个节拍最低视为 3 | P1 |
| 倒计时标记 | 1 | 无 | 延时 2 秒 | 标记目标，倒计时结束时短暂显示其未来轨迹 | P1 |
| 残留推力 | 2 | 强度 D6 | 持续 2 个节拍 | 每个节拍沿同一方向施加小推力 | P2 |

### 延时牌通用反制

延时牌必须给对手清晰反制窗口：

- 地面或目标身上显示倒计时环。
- 倒计时结束前 0.5 秒增强提示。
- 延时区域可以被急刹车、位移、空气墙、接地等方式规避或削弱。
- 延时牌的强度通常高于瞬发牌，但命中难度也更高。

### 持续牌通用限制

持续牌不能无限铺场：

- 每名玩家同时最多维持 2 张持续基础卡。
- 同类持续效果只取最强，不完全叠加。
- 持续牌离场后保留 0.3 秒淡出提示，避免玩家误判。

## 6. 属性卡

属性卡按科学流派分组。首发建议先做力学、电学、数学。

## 9. 流派构筑示例

### 9.1 力学重锤流

核心：

- 质量膨胀
- 直线撞锤
- 碰撞放大器
- 第三定律
- 静摩擦极限

打法：

- 提高质量后靠近敌人。
- 用防反逼敌人不敢正面冲。
- 抓边缘机会用强撞击终结。

### 9.2 电学极性流

核心：

- 正电荷赋予
- 负电荷赋予
- 极性翻转
- 电磁脉冲
- 接地

打法：

- 先给敌人和场景物体挂电荷。
- 利用吸引把敌人拉到边缘。
- 用脉冲完成排斥击飞。

### 9.3 数学降维流

核心：

- 单维坍缩
- 投影线
- 向量消元
- 归一化
- 芝诺的悖论

打法：

- 限制敌人运动方向。
- 让敌人只能沿可预测路径产生位移。
- 用队友或场景机制完成击杀。

### 9.4 概率娱乐流

核心：

- 幸运常数
- 重掷许可
- 小概率奇迹
- 赌徒冲刺
- 方差爆发

打法：

- 依靠骰子制造爆点。
- 不适合排位主流，但适合娱乐和直播。

## 10. 平衡原则

健康卡牌：

- 有清晰用途。
- 有明确反制。
- 掷低点仍有意义。
- 掷高点很爽但不无解。
- 可以和其他卡形成组合。

不健康卡牌：

- 单卡无预警秒杀。
- 让敌人长时间不能操作。
- 视觉上看不懂。
- 必带，否则无法竞争。
- 掷 1 等于完全浪费一回合。
