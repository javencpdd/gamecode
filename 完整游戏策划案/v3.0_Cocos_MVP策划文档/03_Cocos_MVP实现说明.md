# 《力学大乱斗》v3.0 Cocos MVP 实现说明

版本：v3.0  
文档定位：当前工程实现、MCP 使用方式和测试重点

---

## 1. 工程结构

当前 Cocos 项目：

```text
NewProject
```

主场景：

```text
NewProject/assets/scene.scene
```

主脚本：

```text
NewProject/assets/scripts/MechanicsBrawlGame.ts
```

场景根节点：

```text
Canvas/MechanicsBrawl_MVP
```

---

## 2. MCP 当前用途

`link_cc_mcp` 当前用于：

- 检查 Cocos 编辑器是否连接。
- 创建和删除场景节点。
- 挂载 `MechanicsBrawlGame` 组件。
- 保存场景。
- 启动预览。
- 截图和读取日志。

当前 MCP 服务：

```text
http://127.0.0.1:3200/mcp
```

---

## 3. 当前脚本职责

`MechanicsBrawlGame.ts` 暂时是单脚本 MVP，负责：

- 初始化运行时 UI。
- 绘制实验台、角色、手牌和状态。
- 管理双方角色数据。
- 管理双方专属牌库和随机手牌。
- 处理单击看牌、拖卡释放、连续出牌、跳过和结束回合输入。
- 执行骰子点数 1 到 6 的结算。
- 显示卡牌基础数值、点数结果、持续回合和实时属性。
- 执行简化 2D 圆形物理。
- 判定出界得分和游戏结束。

后续如果脚本继续变大，可拆为：

- `TurnController`
- `CardSystem`
- `PhysicsResolver`
- `BattleHud`
- `CharacterData`

当前阶段先保持单脚本，方便快速验证玩法。

---

## 4. 预览测试重点

每次修改后必须至少检查：

1. 预览是否能打开。
2. 当前玩家是否只显示自己的手牌，且上限固定为 6。
3. 艾萨克和麦克斯韦的手牌是否来自不同牌库。
4. 回合开始是否抽 2 张，打出的牌是否被消耗。
5. 单击卡牌是否显示骰子点数 1 到 6 的具体数值。
6. 拖卡时卡牌详情是否随方向和拖拽距离实时更新。
7. 拖卡到场地内是否能释放。
8. 未出牌时“跳过”是否能直接交给对手。
9. 出牌后按钮是否从“跳过”变为“结束”。
10. 出牌后是否进入单张卡结算阶段并锁定输入。
11. 单张卡结算结束后是否仍由当前玩家继续出牌。
12. 点击“结束”或手牌用空后是否换人。
13. 角色出界是否得分并重置。
14. 控制台是否出现新报错。

---

## 5. 当前已知限制

- 还没有角色选择界面。
- 还没有能量系统。
- 对手手牌没有背面显示。
- UI 仍是原型布局。
- 场景只有一张实验台地图。

这些限制不阻塞 v3.0 MVP 验证。优先级最高的是确认“轮流行动 + 连续出牌 + 单张物理结算 + 专属随机手牌”的核心循环是否好玩。
