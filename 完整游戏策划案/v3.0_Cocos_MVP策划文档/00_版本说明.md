# 《力学大乱斗》v3.0 Cocos MVP 版本说明

版本：v3.0  
日期：2026-05-16  
文档定位：记录当前 Cocos 原型的真实规则，作为后续迭代依据

---

## 1. 版本方向

v3.0 从 v2.0 的“轻量 HTML 首版方案”分出一条 Cocos MVP 原型路线。

v2.0 继续保留为轻量 Web/HTML 发布目标；v3.0 重点服务 Cocos Creator 内的可玩验证，用 MCP 快速搭场景、挂脚本、预览和迭代规则。

---

## 2. 核心变化

| 模块 | v2.0 设想 | v3.0 Cocos MVP |
| --- | --- | --- |
| 对局节奏 | 可偏实时，也可回合 | 明确为回合制 |
| 手牌 | 初始 4 张，抽 1 张 | 手牌上限 6；开局 4 张，每回合开始抽 2 张 |
| 卡组 | MVP 可用 12 张固定卡 | 每名角色有自己的专属牌库 |
| 出牌流程 | 选牌、瞄准、释放 | 单击看数值，拖动手牌到实验台内释放；一回合可连续使用多张卡 |
| 物理结算 | 出牌后执行物理 | 每张卡单独结算，结算完成后仍由当前玩家继续出牌 |
| 持续效果 | 可按秒或回合 | 全部按回合数结算，部分卡持续多个回合 |
| 移动方式 | 无自由移动 | 继续坚持无自由移动 |

## 3. 当前 MVP 范围

当前原型只验证一件事：在没有 WASD、摇杆和方向键移动的前提下，玩家能否通过回合制卡牌和物理结算把对手推出实验台。

MVP 内容：

- 角色：艾萨克、麦克斯韦。
- 模式：本地 1v1，轮流出牌。
- 手牌：每名玩家手牌上限 6；开局 4 张，每回合开始抽 2 张，打出的牌会消耗；同一回合可以连续使用多张。
- 卡牌来源：角色专属牌库随机抽取。
- 结算：骰子点数 1 到 6 决定卡牌强度倍率。
- 信息：点击卡牌显示基础力、拖拽倍率、方向、持续回合，以及骰子点数 1 到 6 的具体结果。
- 物理：圆形角色、速度、摩擦、碰撞、出界得分。
- 胜利：先到 3 分获胜。

## 5. 动态策划原则

后续每次代码原型调整，如果改变了玩家操作、回合流程、卡牌效果、角色定位或胜负规则，都必须同步更新 v3.0 文档。

当前以“先验证手感，再扩写系统”为原则：

1. 原型里不好玩或不清晰的规则，优先改规则。
2. 已经在原型中稳定的规则，及时写入文档。
3. 不为了保留旧文档而牺牲当前可玩性。
4. v2.0 HTML 方案不删除，但不再约束当前 Cocos MVP 的工程实现。
