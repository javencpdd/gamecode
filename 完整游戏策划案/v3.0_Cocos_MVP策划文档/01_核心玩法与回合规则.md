# 《力学大乱斗》v3.0 核心玩法与回合规则

版本：v3.0  
文档定位：当前 Cocos MVP 的对局流程、操作方式和结算规则

---

## 1. 核心玩法

《力学大乱斗》v3.0 是一款回合制物理卡牌竞技原型。

玩家不能自由移动。每名玩家在自己的回合从随机手牌中选择一张卡，先单击查看具体数值，再拖到实验台内释放。卡牌会产生冲量、吸引、排斥、刹车、防护或场地效果。随后进入物理结算阶段，双方角色根据速度、摩擦、场力和碰撞移动，直到结算结束。

---

## 2. 标准回合流程

1. 当前玩家获得行动权。
2. 当前玩家从自己的专属牌库抽 2 张，直到手牌达到上限 6。
3. 界面显示当前玩家的手牌；对手手牌暂不展示。
4. 玩家单击卡牌查看基础力、拖拽倍率、方向、持续回合和骰子点数 1 到 6 的结果。
5. 玩家按住一张手牌拖到实验台内；拖拽方向决定力或场力方向，拖拽距离影响倍率。
6. 松手释放，系统掷骰子，得到点数 1 到 6。
7. 根据卡牌基础强度、骰子点数和拖拽倍率计算效果，打出的卡牌被消耗。
8. 进入物理结算阶段，锁定所有出牌输入。
9. 角色运动、碰撞、场地效果和出界判定自动执行。
10. 当速度降到阈值，或达到最大结算时间，切换到下一名玩家。

玩家也可以点击“跳过”不出牌，直接交给对手行动。

---

## 3. 回合状态

| 状态 | 说明 | 玩家能做什么 |
| --- | --- | --- |
| 瞄准阶段 | 当前玩家选择并释放卡牌 | 看卡牌数值、拖卡、瞄准、跳过、重开 |
| 结算阶段 | 物理效果正在执行 | 只能等待或重开 |
| 得分重置 | 有人出界但未结束比赛 | 自动回到场地中央，并重抽手牌 |
| 游戏结束 | 一方达到 3 分 | 点击重开 |

---

## 4. 物理结算结束条件

满足任意条件即结束本次结算：

- 双方总速度低于阈值，且结算已持续一小段时间。
- 结算达到最大时间，当前 MVP 暂定约 4.5 秒。
- 有玩家出界并完成得分判定。

如果速度已经很低，系统会把残余速度清零，避免玩家在下一回合瞄准时角色继续滑动。

---

## 5. 操作方式

当前 Cocos MVP 使用键鼠优先：

| 操作 | 当前规则 |
| --- | --- |
| 使用卡牌 | 鼠标按住底部手牌并拖动 |
| 查看卡牌 | 单击底部手牌，显示具体数值和点数表 |
| 释放卡牌 | 在实验台内松开鼠标 |
| 取消释放 | 松手位置不在实验台内 |
| 瞄准方向 | 释放点相对于当前角色的位置决定方向 |
| 跳过回合 | 点击右上角“跳过”按钮 |
| 重开 | 点击右上角“重开”按钮 |

保留兼容操作：点选卡牌后，也可以在实验台内拖拽释放方向。

---

## 6. 胜负规则

- 角色离开实验台安全边界后判定出界。
- 对方获得 1 分。
- 得分后双方回到初始位置。
- 双方重新洗牌，开局手牌回到 4 张。
- 先达到 3 分的一方获胜。

---

## 7. 设计约束

必须保留：

- 无 WASD。
- 无摇杆自由移动。
- 无持续按键加速。
- 所有位移都必须来自卡牌、场力、碰撞或出界重置。

当前暂不实现：

- 联机。
- 复杂构筑编辑器。
- 血量系统。
- 多地图切换。
- 复杂多边形刚体。
