# 《力学大乱斗》玩法大纲

版本：v1.0  
文档定位：对局流程、胜利条件、核心规则、模式设计、操作与资源系统

---

## 1. 玩法核心

《力学大乱斗》的核心玩法是“卡牌驱动位移 + 掷骰结算 + 物理碰撞”。玩家不能通过 WASD、摇杆、方向键或虚拟摇杆产生自由移动，角色的一切位置变化都来自卡牌、角色技能、场景机制和物理碰撞。

玩家每局需要同时处理：

- 自己的位置。
- 自己当前速度方向和惯性。
- 敌人的速度和状态。
- 手牌和能量。
- 骰子可能带来的强化或失准。
- 场地边缘和地图机制。

游戏不是传统动作走位，也不是血条对砍，而是通过“何时打出哪张位移/施力卡”制造位置优势，再将敌人击出场外或撞到结构崩坏。

---

## 2. 单局流程

### 2.1 标准流程

1. 进入房间。
2. 选择角色。
3. 选择卡组。
4. 系统随机或玩家投票选择地图。
5. 开局倒计时 3 秒。
6. 玩家选择卡牌、瞄准方向/区域、掷骰、结算物理效果、争夺位置。
7. 触发击飞、结构崩坏或计分。
8. 时间结束或一方达成胜利条件。
9. 结算数据。
10. 返回房间或快速再战。

### 2.2 推荐对局参数

| 参数 | MVP | 完整版 |
| --- | --- | --- |
| 单局人数 | 2 | 2-4 |
| 单局时间 | 180 秒 | 180-360 秒 |
| 初始手牌 | 4 | 4 |
| 卡组大小 | 12 | 15 |
| 能量上限 | 10 | 10-12 |
| 能量回复 | 1 点/秒 | 0.8-1.2 点/秒 |
| 稳定性血量 | 100 | 100 |
| 复活时间 | 无或 3 秒 | 3-5 秒 |
| 出界挣扎时间 | 0.7 秒 | 0.7-1 秒 |

## 3. 操作设计

### 3.1 操作原则

本游戏不提供主动移动输入。玩家不能按住方向键让角色持续向左、向右、向上或向下移动。

玩家能做的操作只有：

- 选择手牌或常驻基础指令卡。
- 瞄准方向、目标或区域。
- 确认释放卡牌。
- 使用角色主动技能或终极技能。
- 取消瞄准、查看状态、查看轨迹预览。

### 3.2 键鼠操作

| 操作 | 方案 |
| --- | --- |
| 瞄准方向/区域 | 鼠标移动 |
| 使用手牌 | 数字键 1-4 / 鼠标点击 |
| 使用常驻基础指令卡 | Q / E / 鼠标点击指令槽 |
| 主动技能 | Shift |
| 终极技能 | R |
| 取消瞄准 | 右键 / Esc |
| 查看状态与轨迹 | Tab |

### 3.3 手柄操作

| 操作 | 按键 |
| --- | --- |
| 瞄准方向/区域 | 右摇杆 |
| 选择手牌 | LB/RB |
| 使用卡牌 | A |
| 使用常驻基础指令卡 | X / B |
| 主动技能 | RT |
| 终极技能 | Y |
| 取消瞄准 | Back |

左摇杆不用于移动。若使用手柄，左摇杆可用于选择 UI、切换目标或调整镜头视角，但不能直接驱动角色位移。

### 3.4 移动端操作

| 操作 | 方案 |
| --- | --- |
| 瞄准方向/区域 | 右侧拖拽 |
| 使用手牌 | 点击底部手牌 |
| 使用常驻基础指令卡 | 点击固定指令按钮 |
| 主动技能 | 技能按钮 |
| 终极技能 | 终极按钮 |
| 取消 | 拖拽回中心或取消按钮 |

移动端不设置虚拟移动摇杆。屏幕左侧可用于拖动镜头或快速查看状态，不产生角色位移。

### 3.5 位置变化来源

角色位置只能通过以下来源改变：

| 来源 | 示例 |
| --- | --- |
| 自己打出的位移卡 | 矢量冲刺、回场抓钩、坐标平移 |
| 自己打出的刹车/转向卡 | 急刹车、轨迹修正、矩阵旋转 |
| 角色技能 | 空间折叠、洛伦兹漂移 |
| 敌方卡牌 | 电磁脉冲、引力井、边缘推手 |
| 场景机制 | 磁轨、冰面、引力核心、空间门 |
| 物理碰撞 | 撞击、反弹、推挤、爆炸冲量 |

这条规则是项目底层原则：任何“左右移动”“走位”“回场”都必须表现为一次卡牌或物理事件。

## 4. 核心物理规则

### 4.1 实体属性

每个玩家、障碍、召唤物都拥有以下属性。

| 属性 | 说明 |
| --- | --- |
| mass | 质量，影响被击退和撞击强度 |
| velocity | 当前速度向量 |
| angularVelocity | 角速度，影响旋转和轨道 |
| friction | 摩擦，影响减速和刹车 |
| restitution | 弹性，影响碰撞反弹 |
| charge | 电荷，分正、负、中性 |
| stability | 结构稳定性，类似生命值 |
| heat | 热量，影响热学效果 |
| statusTags | 当前状态标签 |

### 4.2 卡牌驱动位移与冲量规则

大部分位移和击退使用冲量，而不是直接改位置。玩家没有基础加速度输入，不能靠按键持续加速；只有卡牌和场景能改变速度。

```text
deltaVelocity = impulse / mass
```

设计效果：

- 重角色更难被推走。
- 轻角色使用位移卡时更容易获得速度，但也更容易被击飞。
- 同样一张卡，对不同质量角色产生不同手感。

### 4.3 自然惯性

角色在没有卡牌输入时仍会遵守物理惯性：

- 如果角色已有速度，会继续滑行并受摩擦影响逐渐减速。
- 如果角色静止，除非受到卡牌、碰撞或场景机制影响，否则不会自行移动。
- 玩家不能在滑行过程中用方向键微调，只能使用轨迹修正、急刹车、矩阵旋转等卡牌改变运动。

### 4.4 碰撞伤害

高速碰撞造成结构伤害。

```text
relativeSpeed = length(vA - vB)
impactEnergy = 0.5 * reducedMass * relativeSpeed^2
damage = clamp((impactEnergy - threshold) * damageScale, 0, maxDamage)
```

简化理解：

- 撞得越快，伤害越高。
- 越重的角色高速撞击越危险。
- 低速擦碰不会造成大量伤害。

### 4.5 出界规则

1. 玩家离开安全边界后进入失控区。
2. 进入失控区后开始 0.7 秒倒计时。
3. 倒计时结束仍未回到安全区，判定坠落。
4. 失控区内可以使用回场牌、常驻基础指令卡和技能。
5. 最后一次对该玩家施加有效外向冲量的人获得击飞归属。

## 5. 资源系统

### 5.1 能量

能量用于使用卡牌。

规则：

- 能量上限默认 10。
- 每秒回复 1。
- 高消耗卡需要 5-7 能量。
- 资源卡可以临时恢复能量或降低消耗。

设计目的：

- 防止连续使用强牌。
- 让玩家在进攻、防守和铺垫之间取舍。

### 5.2 手牌

规则：

- 开局抽 4 张。
- 使用一张卡后抽 1 张。
- 牌库抽空后洗弃牌堆。
- 手牌最多 5 张，超过上限需要弃牌或延迟抽牌。

### 5.3 卡牌驱动位移保底

因为玩家不能自由移动，系统必须避免“手上没有位移牌就完全动不了”的挫败感。

保底规则：

- 每套卡组至少携带 3 张位移/回场牌。
- 开局手牌至少包含 1 张位移牌；若没有，系统自动重抽。
- 每名玩家拥有 2 张常驻基础指令卡，不进入牌库，占用独立指令槽。
- 常驻基础指令卡仍然是卡牌，需要消耗能量或冷却，不是自由移动。
- 如果玩家连续 8 秒没有打出任何位置改变类卡牌，下一次抽牌优先抽到位移或回场牌。

常驻基础指令卡建议：

| 指令卡 | 消耗 | 冷却 | 效果 |
| --- | --- | --- | --- |
| 微型推进 | 1 | 3 秒 | 向瞄准方向施加小冲量，主要用于微调和脱困 |
| 紧急制动 | 1 | 5 秒 | 短时间提高摩擦，降低当前速度 |

设计边界：

- 常驻指令卡强度低，不能替代真正的位移牌。
- 常驻指令卡要有卡牌动画和能量反馈，避免被误解为移动键。
- 排位和娱乐模式都保留该机制，保证基础可玩性。

### 5.4 终极能量

获得方式：

- 造成结构伤害。
- 完成击飞。
- 成功防反。
- 被击飞后少量补偿。
- 完成场景目标。

设计原则：

- 终极不应开局即可释放。
- 落后方可以获得少量追赶机会。
- 终极技能需要明显预警。

## 6. 战斗节拍与延时结算

为了支持延时技能卡和持续多个回合的卡牌，实时模式中引入“战斗节拍”概念。

### 6.1 战斗节拍定义

实时模式：

- 默认每 5 秒为 1 个战斗节拍。
- 持续多回合卡牌按节拍结算。
- 节拍不会暂停实时物理运动，只用于状态和卡牌计时。

桌游/回合模式：

- 每个玩家完成一次行动后，视为推进 1 回合。
- “持续 N 个节拍”可直接改为“持续 N 回合”。

### 6.2 延时卡结算

延时卡使用后不会立即完整生效，而是进入倒计时。

流程：

1. 玩家使用延时卡并选择目标或区域。
2. 卡牌消耗能量并开始倒计时。
3. 地面、目标或角色身上显示倒计时环。
4. 倒计时结束时触发效果。
5. 若卡牌带骰子，可以在释放时掷骰，也可以在结算时掷骰。

建议：

- 强度固定的延时牌在释放时掷骰，方便玩家预期结果。
- 位置相关的延时牌在结算时掷骰，制造临场变化。
- 所有延时牌都必须有清晰预警。

### 6.3 持续多节拍卡结算

持续卡会在多个节拍内重复生效。

常见类型：

| 类型 | 说明 |
| --- | --- |
| 每节拍触发 | 每个节拍开始时结算一次效果 |
| 每节拍衰减 | 效果强度逐节拍下降 |
| 每节拍增强 | 效果逐节拍增强，但有上限 |
| 维持消耗 | 每个节拍消耗能量，否则提前结束 |
| 条件触发 | 持续期间满足条件才触发 |

示例：

- “熵增记录”：持续 3 个节拍，每个节拍提高目标热量。
- “电荷维持”：持续 3 个节拍，使目标电荷不会自然衰减。
- “持续校准”：持续 3 个节拍，每个节拍改善第一次掷骰结果。

### 6.4 准备型卡牌

准备型卡牌挂在玩家身上，满足条件才触发。

示例：

- 预载护盾：受到下一次撞击时自动展开。
- 保险抓钩：进入失控区时自动回场。
- 反应实验：敌方对你出牌时自动反制。

限制：

- 每名玩家同时最多携带 2 个准备效果。
- 同类准备效果只保留最新一个。
- 准备效果必须在角色状态栏显示。

### 6.5 中断与反制

延时和持续卡需要反制方式。

可中断情况：

- 施法者被击飞出界。
- 施法者结构崩坏。
- 目标离开范围。
- 区域被相反场地卡覆盖。
- 特定净化卡清除状态。

可削弱情况：

- 急刹车降低延时冲量效果。
- 接地削弱延时放电。
- 绝热护层削弱热学持续牌。
- 坐标平移躲开坍缩预告。

### 6.6 可读性要求

延时和持续牌最怕“看不懂”。因此必须满足：

1. 倒计时清晰。
2. 影响范围清晰。
3. 每次节拍结算有轻微音效。
4. 最后一次结算有明显提示。
5. 战斗 HUD 显示自己身上的准备效果。
6. 地图上同屏倒计时区域不宜超过 4 个。

## 7. 掷骰玩法

### 7.1 触发时机

以下卡牌或行为可能触发掷骰：

- 使用带骰子的卡牌。
- 角色技能需要随机强度。
- 场景事件需要随机方向。
- 特殊模式中的命运事件。

### 7.2 结算流程

1. 玩家选择卡牌和目标。
2. 系统检查能量和合法目标。
3. 如果卡牌需要掷骰，显示骰子动画。
4. 应用角色、场景、卡牌修正。
5. 结算保底效果。
6. 根据骰子点数强化效果。
7. 显示结果提示。

### 7.3 战斗节奏要求

- 普通掷骰动画不超过 0.4 秒。
- 高级特殊卡可短暂慢动作。
- 掷骰不能打断实时物理结算太久。
- 敌方骰子结果必须可见，但信息要简洁。

## 8. 胜利条件

## 8.1 地形杀

目标：将敌人击出安全边界。

适用：

- 1v1。
- 4 人混战。
- 团队战。

优点：

- 直观。
- 戏剧性强。
- 能体现物理击退乐趣。

注意：

- 必须提供回场机会。
- 边缘提示要明显。
- 击飞归属要公平。

## 8.2 结构崩坏

目标：将敌人稳定性打到 0。

适用：

- 有墙场地。
- 新手局。
- 小地图。

规则：

- 高速撞击造成结构伤害。
- 稳定性低时角色更容易被击飞。
- 稳定性归零后角色解体并失去一条命或判负。

## 8.3 计分胜利

限时内分数最高获胜。

计分建议：

| 行为 | 分数 |
| --- | --- |
| 击飞对手 | +3 |
| 结构崩坏 | +3 |
| 三卡以上连锁击飞 | +1 |
| 防反击杀 | +1 |
| 占据实验核心 10 秒 | +1 |
| 自己坠落 | -1 |

## 8.4 团队目标

2v2 可加入团队目标：

- 撞击中立能量球进入对方区域。
- 保护己方实验核心。
- 抢占接地平台。
- 共同把敌人推入引力坍缩区。

## 8.5 突然死亡

若时间结束仍平局：

1. 安全区开始缩小。
2. 能量回复提高。
3. 场地摩擦降低。
4. 中央出现强引力核心。
5. 30 秒后仍未结束，进入全场高危状态。

## 9. 状态系统

### 9.1 常见状态

| 状态 | 效果 |
| --- | --- |
| 高质量 | 抗击飞提高，转向下降 |
| 低质量 | 位移卡造成的速度变化提高，被击飞更远 |
| 正电荷 | 与负电荷吸引，与正电荷排斥 |
| 负电荷 | 与正电荷吸引，与负电荷排斥 |
| 接地 | 清除电荷并抗电 |
| 减速 | 速度上限、当前速度或下一张位移卡效果下降 |
| 失衡 | 受到侧向力时效果增强 |
| 过热 | 转向下降，受到额外结构伤害 |
| 轨道 | 绕指定点运动 |
| 降维 | 只能沿指定轴产生位移和速度变化 |

### 9.2 控制抗性

为避免连续控制导致无法操作：

| 控制 | 抗性 |
| --- | --- |
| 击飞 | 1.5 秒内再次击飞效果降低 30% |
| 定身 | 4 秒内最多触发一次完整定身 |
| 引力吸引 | 同类吸引只取最强 |
| 降维 | 离开区域后 2 秒免疫再次降维 |
| 电荷翻转 | 1 秒内不能被连续翻转超过 2 次 |

## 10. 模式设计

## 10.1 教学模式

目标：5 分钟让玩家理解核心规则。

关卡顺序：

1. 理解“不能自由移动，必须用卡牌产生位移”和瞄准。
2. 使用矢量冲刺撞击假人。
3. 用急刹车停在边缘前。
4. 从失控区使用回场抓钩。
5. 赋予正负电荷并用电磁脉冲结算。
6. 完成一次完整击飞。

## 10.2 快速决斗

规则：

- 1v1。
- 三局两胜。
- 每局 180 秒。
- 固定或半固定卡组。

适合：

- 主循环。
- 排位基础。
- 平衡测试。

## 10.3 四人混战

规则：

- 4 人混战对局。
- 每人 3 条命或限时计分。
- 地图事件更频繁。

设计重点：

- 特效不能过乱。
- 击飞归属必须清楚。
- 高消耗全场卡要限制数量。

## 10.4 团队实验

规则：

- 2v2。
- 队友之间卡牌效果默认减弱。
- 可以用引力、抓钩等方式救队友。
- 团队共享分数。

## 10.5 沙盒实验室

功能：

- 自定义地图。
- 调整摩擦、质量、能量回复。
- 开关轨迹线和力矢量。
- 测试卡牌和连招。
- 适合开发调试和玩家练习。

## 10.6 娱乐骰子模式

规则：

- 开放混沌骰和命运骰。
- 每 30 秒全场随机事件。
- 卡牌可能出现额外随机分支。

适合：

- 派对。
- 直播。
- 非排位。

## 11. 连招系统

### 11.1 连招判定

若玩家在 4 秒内使用多张卡牌，并由同一目标的连续状态导致击飞或结构崩坏，则记录为连招。

连招等级：

| 等级 | 条件 |
| --- | --- |
| 2 连 | 两张卡配合造成有效击退 |
| 3 连 | 三张卡配合造成击飞或高伤害 |
| 实验连锁 | 包含属性状态、骰子高点和场景机制 |

### 11.2 连招示例

基础撞击：

- 矢量冲刺 -> 直线撞锤 -> 撞击敌人。

电磁出界：

- 正电荷赋予 -> 负电荷赋予障碍 -> 电磁脉冲。

数学轨道炮：

- 单维坍缩 -> 投影线 -> 质量膨胀 -> 矢量冲刺。

引力弹弓：

- 引力井 -> 角动量守恒 -> 切线释放 -> 撞击敌人。

防反击杀：

- 弹性护盾 -> 敌人冲刺撞击 -> 第三定律 -> 边缘推手。

## 12. UI 与反馈

### 12.1 战斗 HUD

必须显示：

- 稳定性。
- 能量。
- 手牌。
- 主动技能冷却。
- 终极能量。
- 电荷、质量、热量等关键状态。
- 出界倒计时。
- 最近一次骰子结果。
- 当前延时卡倒计时。
- 当前准备效果。
- 持续多节拍卡的剩余节拍数。

### 12.2 瞄准预览

| 卡牌类型 | 预览 |
| --- | --- |
| 冲刺 | 方向箭头和预计距离 |
| 区域 | 圆形或矩形范围 |
| 电磁 | 带电实体之间的力线 |
| 引力 | 吸引半径和中心点 |
| 投影 | 线段和投影方向 |
| 骰子牌 | 显示骰子图标和可能影响参数 |
| 延时牌 | 显示倒计时、触发范围和最终方向 |
| 持续牌 | 显示剩余节拍和下一次结算时间 |

### 12.3 高危提示

必须醒目：

- 即将出界。
- 敌方终极释放。
- 大范围场地坍缩。
- 自身被强引力吸引。
- 自身处于高热或低稳定状态。
- 敌方延时大招即将触发。

## 13. 技术实现建议

### 13.1 MVP 技术路线

1. 本地 1v1。
2. Matter.js 物理碰撞。
3. 简单卡牌系统。
4. D6 掷骰。
5. 出界与血量。
6. 基础 UI。
7. 两张地图。

### 13.2 联机方向

建议服务端权威：

- 客户端发送输入和出牌意图。
- 服务端校验能量、冷却、目标。
- 服务端计算物理结果。
- 客户端做预测和插值。

如果时间紧：

- 先完成本地同屏。
- 再完成简单房间同步。
- 最后做服务端权威和回滚优化。

### 13.3 调试工具

建议开发隐藏调试面板：

- 显示速度向量。
- 显示质量和摩擦。
- 显示电荷。
- 显示最近一次冲量来源。
- 手动设置骰子点数。
- 手动推进战斗节拍。
- 查看延时卡队列。
- 切换场景机制。
- 重置玩家位置。

## 14. 玩法验收标准

一个版本是否好玩，可用以下问题判断：

1. 玩家是否能理解自己为什么被击飞？
2. 出界后是否有救回来的机会？
3. 掷骰结果是否让人期待，而不是焦虑？
4. 基础卡是否足够可靠？
5. 属性卡是否能形成不同流派？
6. 一局是否能自然出现高光连招？
7. 场景机制是否参与战斗？
8. 胜负是否主要来自选择和操作，而不是纯随机？
