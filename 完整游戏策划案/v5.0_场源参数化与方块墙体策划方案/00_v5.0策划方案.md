# 《力学大乱斗》v5.0 场源参数化与方块墙体策划方案

版本：v5.0  
日期：2026-05-17  
定位：在 v4.0 “回合内规划 + 回合末统一物理结算”基础上，强化可计算性、角色辨识、场源参数控制、墙体节奏和边界信息表达

---

## 1. v5.0 目标

v5.0 保留 v4.0 的核心规则：行动回合内只做规划，回合结束后播放骰子过场，再统一结算 1 秒物理运动。

本版重点解决 5 个问题：

1. 角色辨识不足：角色必须有明确姓名，并在战场、HUD 和角色图像中同步显示。
2. 固定场源控制不足：玩家不能只指定坐标，必须能设置方向和数值大小。
3. 墙体出现过频、过强：降低墙体相关卡牌抽取概率，并改为方块单位逐步建造和逐步破坏。
4. 场源反馈偏弱：允许场源持续时间更长、数值上限适度提高，但必须受 UI 边界限制。
5. 计算信息不足：增加角色到上下左右边界的距离，帮助玩家判断出界风险。
6. 音频反馈缺失：接入开始界面、战斗、骰子、风、冰、电荷电击对应音频素材。

## 2. 角色命名与辨识

正式角色名：

| 阵营 | 角色名 | 定位 |
| --- | --- | --- |
| 牛顿方 | 艾萨克·牛顿 | 高质量、高摩擦、墙体与惯性控制 |
| 麦克斯韦方 | 詹姆斯·麦克斯韦 | 电荷、风场、场源方向控制 |

显示规则：

- 战场角色头顶显示角色名。
- HUD 属性面板显示完整角色名。
- 回合提示、胜负提示、抽牌提示统一使用角色名。
- 战场角色主体使用对应角色图像，不再使用纯色圆形占位。

### 2.1 角色图像资源

角色图像放入 Cocos 资源目录：

```text
NewProject/assets/resources/characters/
```

映射规则：

| 文件 | 资源路径 | 对应角色 | 用途 |
| --- | --- | --- | --- |
| N.png | characters/N/spriteFrame | 艾萨克·牛顿 | 战场角色主体 |
| M.jpg | characters/M/spriteFrame | 詹姆斯·麦克斯韦 | 战场角色主体 |

显示要求：

- 角色图像跟随角色物理位置移动。
- 图像大小按角色半径缩放，仍以角色圆形碰撞半径作为真实物理边界。
- 受力箭头、电荷环、选中高亮和角色名仍绘制在图像之上。
- 如果图像加载失败，允许回退到 v4/v5 原型的纯色圆形占位。

## 3. 固定场源参数化

### 3.1 基础规则

玩家使用固定场源卡时，流程调整为：

1. 将场源卡拖放到地图位置。
2. 系统打开“场源参数面板”。
3. 玩家通过转盘设置方向。
4. 玩家通过数字框设置场源大小。
5. 玩家确认后，卡牌才被消耗并进入计划队列。
6. 玩家取消时，卡牌保留在手牌中。

重要时序：

- 参数设置阶段仍属于行动回合规划，不改变正式场景。
- 确认后的场源仍然只是计划项。
- 只有行动结束、骰子过场完成后，场源才转化为正式 `FieldSource` 并参与 1 秒结算。

### 3.2 方向设置

方向使用 0 到 360 度圆形转盘。

规则：

- 方向范围：0 到 360 度。
- UI 步进：每次按钮调整 15 度。
- 玩家也可以直接点击转盘位置设置方向。
- 风场方向直接决定风力方向。
- 电荷点方向作为“电场偏置方向”，在径向电磁力之外提供弱方向偏置，用于增强玩家对场源形态的控制。

### 3.3 数值大小设置

数字框显示单位为 N。

推荐范围：

| 场源 | 默认值 | 最小值 | 最大值 | 步进 |
| --- | ---: | ---: | ---: | ---: |
| 轻风标记 | 0.85 N | 0.30 N | 1.60 N | 0.05 N |
| 静电标记 | 1.05 N | 0.40 N | 1.80 N | 0.05 N |
| 微型电荷点 | 1.25 N | 0.50 N | 2.20 N | 0.05 N |
| 风矢量 | 1.10 N | 0.40 N | 2.00 N | 0.05 N |

全局硬上限：

- 单个场源最大作用力不超过 3.0 N。
- 场源强化类卡牌也不能突破 3.0 N。
- 每名玩家同时拥有的场源数量仍建议限制为 3 个。

## 4. 场源持续时间与数值增强

v5.0 允许场源持续时间增强，以提高规划价值。

推荐调整：

| 卡牌 | v4.0 持续 | v5.0 持续 |
| --- | ---: | ---: |
| 轻风标记 | 2 s | 3 s |
| 静电标记 | 3 s | 4 s |
| 微型电荷点 | 3 s | 4 s |
| 风矢量 | 2 s | 3 s |
| 粗糙地带 | 3 s | 4 s |
| 光滑地带 | 2 s | 3 s |
| 静止参考系 | 2 s | 3 s |

平衡约束：

- 场源数值可以提高，但必须通过参数面板显性展示。
- 场源持续时间增加后，抽牌概率应适当降低，避免场面堆满场源。
- 若场源超过拥有上限，优先移除剩余时间最短的己方场源。

## 5. 方块墙体系统

### 5.1 最小单位

v5.0 墙体统一由正方形最小单位构成。

正式单位：

```text
1 个墙体方块 = 0.4 m x 0.4 m
1 个墙体方块 = 1 点耐久
```

所有墙体，包括地图初始墙体、玩家建造墙体，都可以被破坏。

### 5.2 建造规则

墙体不再一次生成长条，而是通过方块慢慢建造。

| 卡牌 | 建造量 | 说明 |
| --- | ---: | --- |
| 方块筑墙 | 1 格 | 基础墙体卡，低概率抽取 |
| 牛顿砖列 | 2 格 | 牛顿专属，按当前方向横向或纵向排列 |

建造限制：

- 不能重叠角色。
- 不能放在地图中心禁建区。
- 不能超出地图边界。
- 每名玩家同时拥有的临时墙仍建议限制为 2 组。

### 5.3 破坏规则

破坏也按方块单位逐步发生。

| 卡牌 | 破坏量 |
| --- | ---: |
| 方块拆除 | -1 格 |
| 支点拆解 | -2 格 |

破坏规则：

- 所有墙体均可被指定破坏。
- 墙体耐久归零时，整组墙体移除。
- 被破坏的墙体方块不产生弹性反弹。
- 墙体碰撞仍为无弹性：法线速度吸收，切线速度按墙体摩擦衰减。

## 6. 抽牌概率调整

v5.0 不改变“每回合抽 2 张、手牌上限 6 张”的基础规则，但调整卡牌权重。

推荐权重：

| 卡牌类型 | 抽取权重 |
| --- | ---: |
| 角色属性牌 | 1.30 |
| 基础数学牌 | 0.90 |
| 摩擦/阻尼区域 | 0.75 |
| 风场/电荷场源 | 0.55 |
| 建墙/破墙 | 0.22 |

额外约束：

- 如果手牌中已经有同类建墙或破墙牌，该类卡权重再次乘以 0.35。
- 目标是让墙体成为关键时机工具，而不是常规铺场手段。

## 7. 边界距离信息

HUD 必须显示每个角色到上下左右边界的距离。

计算方式：

```text
左边距 = 角色圆心 x - 角色半径 - 地图左边界 x
右边距 = 地图右边界 x - (角色圆心 x + 角色半径)
上边距 = 地图上边界 y - (角色圆心 y + 角色半径)
下边距 = 角色圆心 y - 角色半径 - 地图下边界 y
```

单位：m。

用途：

- 帮助玩家判断出界风险。
- 帮助玩家计算风场、电荷点、墙体阻挡的收益。
- 提高“物理卡牌对战”的可计算性。

## 8. v5.0 MVP 验收标准

v5.0 MVP 至少满足：

- 角色头顶和 HUD 中显示明确姓名。
- 场源卡拖放后打开参数面板。
- 参数面板包含方向转盘和作用力数字框。
- 方向和数值都有上下限。
- 确认参数后才消耗手牌并进入计划队列。
- 场源在回合结束和骰子过场后才正式生效。
- 场源持续时间和数值较 v4.0 有增强，但不超过全局硬上限。
- 墙体以 0.4 m 正方形为最小单位。
- 建墙和破墙都按方块单位逐步进行。
- 所有墙体都可破坏。
- 建墙/破墙卡抽取概率明显降低。
- HUD 显示角色到上下左右边界的距离。
- 开始界面、游戏中、掷骰、风场、冰面、电荷电击均有对应音频素材触发。
- 牛顿和麦克斯韦均使用对应角色图像资源，并保留碰撞半径和数值显示。

## 9. 音频素材接入规则

### 9.1 资源路径

音频素材统一放入 Cocos 资源目录：

```text
NewProject/assets/resources/audio/
```

资源映射：

| 素材文件 | 资源路径 | 用途 | 播放方式 |
| --- | --- | --- | --- |
| start.mp3 | audio/start | 开始界面背景音乐 | 循环 BGM |
| game.mp3 | audio/game | 游戏进行时背景音乐 | 循环 BGM |
| num.mp3 | audio/num | 开局骰子与回合末骰子 | 单次播放 |
| wind.mp3 | audio/wind | 风场/吹风卡牌 | 单次播放 |
| ice.mp3 | audio/ice | 冰面/低摩擦卡牌 | 单次播放 |
| electronic.mp3 | audio/electronic | 电荷点、电荷翻转、电击反馈 | 单次播放 |

### 9.2 触发时机

| 场景 | 触发 |
| --- | --- |
| 进入开始界面 | 播放 start 循环 BGM |
| 点击开始并进入比赛 | 切换到 game 循环 BGM |
| 开局决定先手骰子 | 播放 num |
| 回合结束骰子过场 | 播放 num |
| 风场计划转为正式场源 | 播放 wind |
| 冰面/低摩擦区域转为正式场源 | 播放 ice |
| 电荷点、电荷翻转、放电校准生效 | 播放 electronic |

### 9.3 音量与优先级

推荐音量：

- start BGM：0.42。
- game BGM：0.34。
- 骰子、风、冰、电击单次音效：0.70 到 0.80。

规则：

- BGM 同一时间只允许一条循环播放。
- 单次音效可以覆盖或叠加，但不改变物理结果。
- 若素材尚未加载完成，允许使用临时合成音作为 fallback。

## 10. 后续风险

主要风险：

- 场源可调数值会增加玩家计算负担，需要清晰预览。
- 场源数值增强后，出界速度可能变快，需要通过边界距离 HUD 和数值上限控制。
- 方块墙体若数量继续扩张，碰撞检测会变重；后续需要独立 `WallGridSystem`。
- 音乐素材体积较大，后续需要确认移动端加载时间和循环点。
- 当前 MVP 仍是单脚本，v5.0 后若继续增加内容，应正式拆分系统模块。
